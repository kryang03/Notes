# 03 Foundations: RL, Stochastic Process, Information Theory

## Reinforcement Learning

### Q001. 为什么灵巧操作中的 RL 不能只按标准 MuJoCo locomotion 经验来设计？

**标准答案：** 灵巧操作包含高维手指、接触模式切换、摩擦不确定性、稀疏成功信号、执行器带宽限制和 sim-to-real gap。locomotion 中相对连续的接触节律在手内操作中变成非平滑、多点、细尺度接触。算法不仅要最大化奖励，还要处理感知、控制频率、接触安全和真实数据效率。

**评分要点：** 必须点出非平滑接触和真实迁移约束。

### Q002. 策略梯度定理的核心价值是什么？

**标准答案：** 它给出 $\nabla_\theta J(\theta)=\mathbb{E}[\nabla_\theta\log \pi_\theta(a|s)Q^\pi(s,a)]$，使我们不用对环境动力学求导，也能通过采样估计策略参数梯度。对接触丰富任务，这很重要，因为真实接触动力学不可微或未知。

**评分要点：** 必须说明“不需要环境动力学可微”。

### Q003. PPO 的 clipped objective 试图防止什么问题？

**标准答案：** PPO 用概率比 $r_t(\theta)$ 的裁剪限制新旧策略差异，防止一次更新过大导致策略崩溃。它近似 TRPO 的 trust region 思想，但实现更简单。灵巧手训练中，过大更新会破坏已学到的接触时序，导致成功率突然归零。

**评分要点：** 必须讲出限制策略更新幅度。

### Q004. SAC 的最大熵目标为什么适合接触丰富任务？

**标准答案：** SAC 最大化奖励和策略熵，使策略保持探索和多样性。接触任务常有多个可行接触序列和动作模式，熵正则能避免过早收敛到脆弱单一路径，并提高 off-policy 样本效率。温度参数控制探索和利用的权衡。

**评分要点：** 必须连接多模态接触策略与熵。

### Q005. TD3 的 target policy smoothing 解决什么偏差？

**标准答案：** TD3 在目标动作上加入小噪声并裁剪，相当于对 Q 函数局部平滑，减少 actor 利用 critic 尖锐误差峰值造成的过估计和不稳定。配合双 critic 取最小值和延迟 actor 更新，提高连续控制稳定性。

**评分要点：** 必须提到 Q 过估计和局部平滑。

### Q006. Offline RL 的核心风险是什么？为什么 CQL/IQL 等方法要保守？

**标准答案：** Offline RL 只能使用固定数据集，策略一旦选择数据分布外动作，Q 函数可能因外推误差给出虚高价值。保守方法压低 OOD 动作价值或避免显式最大化未知动作，防止策略被错误 Q 值吸引。机器人数据昂贵时，保守性比激进探索更安全。

**评分要点：** 必须说出 distribution shift 和 extrapolation error。

### Q007. HER 为什么能缓解稀疏奖励？

**标准答案：** HER 把失败轨迹中实际达到的状态重新标记为目标，使失败经验变成成功经验。它等价于从数据中自动构造课程，让 agent 学会“如何达到某些状态”，再泛化到原始目标。对多目标操作和二值成功奖励尤其有用。

**评分要点：** 必须提到 hindsight relabeling。

### Q008. Domain Randomization 的成功条件和失败模式分别是什么？

**标准答案：** 成功条件是真实环境落在随机化分布支撑内，且策略能从观测中推断关键隐变量或学到对变化鲁棒的行为。失败模式包括随机化范围过窄漏掉真实模式、范围过宽导致过保守、随机化参数与真实物理不匹配、以及执行器/触觉等结构性 gap 无法靠简单随机化覆盖。

**评分要点：** 必须讲出 support coverage 与过宽/过窄 trade-off。

### Q009. 系统辨识和在线适应相对于 DR 的优势是什么？

**标准答案：** 系统辨识试图估计真实参数，使仿真或策略条件化到具体真实环境；在线适应则在部署时根据历史观测推断隐变量。相比 DR 的“训练时变鲁棒”，辨识/适应更样本高效、更有针对性，但依赖可辨识性、激励覆盖和估计稳定性。

**评分要点：** 必须提到具体化真实环境参数。

### Q010. Diffusion Policy 为什么能表达多模态动作分布？

**标准答案：** 扩散模型从噪声逐步去噪生成动作序列，不需要假设单峰高斯输出。它能学习演示数据中多个可行动作模式，并通过条件观测引导生成一致的 action chunk。对接触任务，一个状态可能对应多种换指或接触序列，扩散策略比 MSE 行为克隆更不容易平均掉动作模式。

**评分要点：** 必须说出避免多模态平均。

## Stochastic Process

### Q011. Itō SDE 中漂移项和扩散项分别代表什么？

**标准答案：** SDE $dx=f(x,t)dt+G(x,t)dW_t$ 中，$f$ 是确定性漂移，描述平均动力学趋势；$GdW_t$ 是随机扩散，描述噪声注入和不确定扰动。灵巧操作中，漂移可来自名义动力学，扩散可来自摩擦变化、传感噪声、接触冲击或未建模执行器扰动。

**评分要点：** 必须区分 deterministic drift 与 stochastic diffusion。

### Q012. Itō calculus 为什么会产生能量漂移问题？

**标准答案：** Itō 引理中二阶项不会消失，噪声通过 Hessian 项影响期望能量变化。因此即使噪声均值为零，非线性系统的能量期望也可能漂移。对接触系统，随机扰动可能系统性改变滑移概率或稳定裕度，不能简单当作零均值误差忽略。

**评分要点：** 必须提到二阶项和零均值噪声仍改变期望。

### Q013. 马尔可夫性质在灵巧手真实系统中为什么常常不成立？

**标准答案：** 单帧观测通常缺少隐藏状态，如执行器温度、摩擦记忆、触觉迟滞、CAN 延迟、物体微滑历史和控制器内部状态。真实系统更接近 POMDP，需要历史窗口、滤波器、RNN/Transformer 或 belief state 来恢复近似马尔可夫性。

**评分要点：** 至少列出三个隐藏状态来源。

### Q014. 参数不确定性、结构不确定性、感知不确定性如何区分？

**标准答案：** 参数不确定性是模型结构正确但质量、摩擦、刚度等参数未知；结构不确定性是模型形式本身缺失，如未建模柔性、stick-slip 或接触拓扑变化；感知不确定性来自传感噪声、遮挡、延迟和状态估计误差。三者需要不同处理：辨识、模型扩展/ensemble、滤波和多模态融合。

**评分要点：** 必须给出对应处理方法。

### Q015. 粒子滤波为什么适合接触状态估计？

**标准答案：** 接触状态后验可能多峰、非高斯，并伴随模式跳变。粒子滤波用样本集合表示 belief，可同时保留多个候选接触状态，并通过触觉/视觉观测更新权重。缺点是高维状态下粒子退化，需要重采样、proposal 设计或 manifold-aware 粒子。

**评分要点：** 必须提到多峰和非高斯。

### Q016. GPR 的均值和方差在动力学学习中分别怎么用？

**标准答案：** 均值给出预测动力学或残差，方差给出 epistemic uncertainty，可用于主动采样、安全约束或 MPC 风险惩罚。数据密集区域方差低，外推区域方差高。对真机学习，方差比单点预测误差更适合决定是否允许探索。

**评分要点：** 必须说明方差用于不确定性驱动决策。

### Q017. MPPI 的权重更新为什么像重要性采样？

**标准答案：** MPPI 采样多条控制噪声轨迹，根据轨迹成本 $S(\tau)$ 赋予权重 $w_i\propto \exp(-S_i/\lambda)$，低成本轨迹权重大，高成本轨迹权重小。控制更新是噪声的加权平均，相当于在采样分布下估计更优控制分布的期望。

**评分要点：** 必须写出指数成本权重的直觉。

### Q018. Stochastic Complementarity Problem 相比 LCP 多解决了什么？

**标准答案：** LCP 假设接触参数确定，而 SCP 将摩擦、间隙、刚度或外部扰动的不确定性纳入互补约束。它更适合真实接触，因为接触是否发生、摩擦阈值和滑移方向都可能随机变化。代价是求解更复杂，常需要采样、机会约束或分布鲁棒近似。

**评分要点：** 必须提到互补约束中的随机参数。

## Information Theory

### Q019. 熵在接触分布中可以表示什么？

**标准答案：** 熵可表示接触状态或物体位姿 belief 的不确定性。高熵意味着系统不知道接触在哪里、物体如何受力或哪个模式正在发生；低熵意味着接触解释集中。主动触摸可通过选择动作降低熵，使后续控制更可靠。

**评分要点：** 必须把熵连接到 belief uncertainty。

### Q020. 互信息为什么适合定义主动感知目标？

**标准答案：** 互信息 $I(X;Y)$ 衡量观测 $Y$ 对未知状态 $X$ 能减少多少不确定性。主动感知选择能最大化预期互信息的动作，即下一次触摸或视角应尽可能区分当前候选状态。它比单纯追踪误差更关注信息增益。

**评分要点：** 必须提到减少未知状态不确定性。

### Q021. GPIS + Next Best Touch 的工作流是什么？

**标准答案：** GPIS 用高斯过程表示物体隐式表面，触摸点作为观测更新表面 belief；Next Best Touch 通过采集函数选择下一个触摸位置，使表面不确定性或预期信息增益最大。这个流程把触觉探索变成概率几何重建问题。

**评分要点：** 必须说出“触摸更新 GPIS，再选下一触点”。

### Q022. 信息瓶颈中的压缩与预测权衡如何用于触觉表征？

**标准答案：** 信息瓶颈希望 latent $Z$ 尽量少保留输入 $X$ 的无关细节，同时尽量保留预测任务变量 $Y$ 所需信息。触觉中，$Z$ 应压缩传感噪声、个体传感器偏差和冗余纹理，同时保留接触位置、法向、滑移和物体属性。过强压缩会丢失控制关键信息，过弱压缩会过拟合噪声。

**评分要点：** 必须讲出 compression-prediction trade-off。

### Q023. Empowerment 在机器人操作中表示什么？

**标准答案：** Empowerment 是 agent 动作对未来状态可控性的信道容量，衡量“我能通过动作影响世界多少”。在灵巧操作中，高 empowerment 状态通常意味着手和物体处于可控接触配置，而掉落或失去接触会使 empowerment 降低。它可作为内在奖励鼓励保持可控性。

**评分要点：** 必须说出动作到未来状态的信道容量。

### Q024. VIME 与 DIAYN 的探索动机有什么不同？

**标准答案：** VIME 通过模型参数 belief 的信息增益奖励探索未知动力学；DIAYN 通过最大化技能与状态之间的互信息学习多样化可区分技能。前者关注减少环境模型不确定性，后者关注无监督发现行为模式。灵巧操作中，VIME 适合系统辨识，DIAYN 适合预训练技能库。

**评分要点：** 必须区分 model uncertainty 与 skill diversity。

### Q025. 为什么 reality gap 可以被看作信息损失？

**标准答案：** 仿真观测和动力学省略了真实世界中的部分信息，如温度、摩擦微结构、触觉噪声、延迟和材料变形。策略在仿真中学到的状态表示到真实环境时变成有信息缺口的表示，导致同一观测对应多个真实隐藏状态。Sim-to-real 的本质之一是补回或适应这些缺失信息。

**评分要点：** 必须解释仿真状态表示遗漏真实隐藏变量。

### Q026. 摩擦与 stick-slip 为什么信息量高？

**标准答案：** stick-slip 的发生时刻、频谱和触觉空间模式揭示局部法向力、摩擦系数、材料属性和接触稳定性。它既是失稳风险信号，也是物体物理属性的观测通道。策略若能捕捉早期滑移，就能在掉落前调整抓握力或接触策略。

**评分要点：** 必须说出既是风险也是信息源。

### Q027. 面试官追问：如何把 ensemble disagreement、互信息和主动数据采集合并到一个真机 RL 流程？

**标准答案：** 先用 ensemble world model 预测候选 action chunk 的下一状态分布，以模型间方差近似 epistemic uncertainty；再估计该候选数据对模型参数或关键隐变量的预期信息增益；最后在安全约束下选择高信息、低风险的动作执行。采集后更新 world model 和策略，形成主动学习闭环。

**评分要点：** 必须包含不确定性估计、安全过滤、更新闭环三步。

### Q028. 为什么 aleatoric uncertainty 和 epistemic uncertainty 要分开？

**标准答案：** Aleatoric 是环境固有随机性，更多数据也难以消除；epistemic 是模型无知，可通过采集数据降低。主动探索应优先追逐 epistemic uncertainty，而不是被高噪声但不可学习的 aleatoric 区域吸引。Ensemble 方差常用于近似 epistemic，不同输出分布方差可表示 aleatoric。

**评分要点：** 必须提到一个可被数据降低，一个不可被数据消除。

### Q029. 如果触觉编码器过度压缩，你会在控制表现上看到什么？

**标准答案：** 策略可能无法区分接触位置、滑移方向、法向力变化或物体局部曲率，表现为抓握调整滞后、换指失败、轻微扰动下掉落、对不同材质泛化差。训练 loss 可能仍好看，因为重建或分类目标没有覆盖控制所需信息。

**评分要点：** 必须把表征损失和控制任务不一致联系起来。

### Q030. 请用一句话概括 RL、随机过程、信息论在灵巧操作中的分工。

**标准答案：** RL 决定如何行动，随机过程描述不确定动力学和 belief 演化，信息论决定应该观测什么、保留什么表征、探索哪里最有价值。三者结合后，灵巧操作系统才能在接触不确定、传感不完美和真机数据昂贵的条件下安全学习。

**评分要点：** 必须给出三者各自角色，而不是混为一谈。

### Q031. TD(0)、SARSA、Q-Learning 和 TD($\lambda$) 的核心差异是什么？

**标准答案：** TD(0) 是给定策略下的单步价值评估，用 $R+\gamma V(s')$ bootstrap 当前 $V(s)$；SARSA 是 on-policy 控制，用下一步实际按当前策略选出的 $A'$ 构造 $R+\gamma Q(s',A')$，会把探索风险纳入价值；Q-Learning 是 off-policy 控制，用 $R+\gamma \max_a Q(s',a)$ 学贪婪最优价值；TD($\lambda$) 用资格迹把 TD error 按 $\gamma\lambda$ 回传给近期访问状态，在 TD(0) 和 Monte Carlo 之间折中。

**评分要点：** 必须区分 SARSA 的实际下一动作和 Q-Learning 的 max，并说明 $\lambda$ 的 credit assignment 作用。

### Q032. PPO 为什么“宏观 on-policy，微观带 off-policy 影子”？

**标准答案：** PPO 每个 epoch 先用当前旧策略 $\theta_{old}$ 采集 rollout，更新结束后这批数据会被丢弃，所以宏观上是 on-policy。可是同一批 rollout 会在多个 mini-epoch 中反复使用；第一次 optimizer step 后，正在更新的策略已变成 $\theta$，数据仍来自 $\theta_{old}$，因此要用重要性采样比 $r_t=\pi_\theta(a_t|s_t)/\pi_{old}(a_t|s_t)$ 和 clipping/KL 限制分布偏移。这是短窗口内的 off-policy-style 样本复用。

**评分要点：** 必须说明 rollout 新鲜性、mini-epoch 复用和 importance ratio。

### Q033. 在 Isaac Gym 灵巧手代码中，policy action 到物理作用通常经历哪些步骤？

**标准答案：** ActorCritic 根据观测输出高层 action，环境 `step` 调用 `pre_physics_step` 把 action 缩放为目标关节角增量，例如 $q^{target}_t=clip(q^{target}_{t-1}+action\_scale\cdot a_t)$。这个目标在 `controlFrequencyInv` 个仿真子步中保持不变；每个子步由显式 PD effort 或仿真器内置 position drive 转成力矩，再执行 `gym.simulate`。因此 control frequency 会改变同一目标被低层 PD 冻结执行的时长。

**评分要点：** 必须提到 action scale、target joint、controlFrequencyInv、PD/position drive。

## Extended Questions

### Q034. 为什么策略梯度中可以减去 baseline 而不引入偏差？

**标准答案：** 因为 $\mathbb{E}_{a\sim\pi}[\nabla_\theta\log\pi_\theta(a|s)b(s)]=b(s)\nabla_\theta\sum_a\pi_\theta(a|s)=0$。Baseline 只改变梯度方差，不改变期望梯度。Value function 作为 baseline 能把“状态本来好坏”从动作优势中剥离。

**评分要点：** 必须说明期望为零和降方差。

### Q035. Advantage 相比 return 的优势是什么？

**标准答案：** Return 衡量绝对回报，方差高且混入状态本身难度；advantage 衡量动作相对当前状态平均水平的好坏，更适合作为策略更新权重。灵巧操作中，困难状态下的小进步也应被奖励，而不是被低绝对 return 淹没。

**评分要点：** 必须说明相对状态基线。

### Q036. GAE 中 $\lambda$ 如何调节偏差和方差？

**标准答案：** $\lambda=0$ 接近一步 TD，方差低但依赖 value 估计、偏差大；$\lambda=1$ 接近 Monte Carlo，偏差低但方差高。常用 $0.95$ 在 rollout 真实奖励和 bootstrap value 之间折中。

**评分要点：** 必须说明 TD 与 MC 两端。

### Q037. PPO value clipping 防止什么？

**标准答案：** Value clipping 限制新 value 相对旧 value 的变化，防止 critic 在旧 rollout 上过度拟合或大幅漂移，破坏 advantage 和策略更新。它与 actor clipping 类似，都是为了保持同一批数据上的更新局部性。

**评分要点：** 必须提到 critic 大幅漂移。

### Q038. PPO bounds loss 为什么常用于连续控制？

**标准答案：** Bounds loss 惩罚策略均值 $\mu$ 超出软边界，避免网络把均值推到 action clamp 外的巨大数值，造成梯度和熵套利。灵巧手中若 $\mu\gg1$，实际动作被 clamp 成满舵，但策略分布参数会病态漂移。

**评分要点：** 必须提到均值漂移和 clamp 外套利。

### Q039. 连续高斯策略的微分熵为什么可以为负？

**标准答案：** 连续分布使用微分熵，不像离散熵必非负。高斯熵为 $\sum_i \log(\sigma_i\sqrt{2\pi e})$，当 $\sigma$ 很小时可为负。负熵通常表示策略非常确定，而不是计算错误。

**评分要点：** 必须区分离散熵和微分熵。

### Q040. 为什么 $\sigma$ 变小会让 policy gradient 变大？

**标准答案：** 高斯 log probability 对均值的梯度为 $(a-\mu)/\sigma^2$，当 $\sigma$ 变小时同样动作偏差产生更大梯度。收敛末期 entropy 下降后，pre-clip grad norm 上升可能是这种方差倒数效应。

**评分要点：** 必须写出或解释 $1/\sigma^2$。

### Q041. 单峰高斯策略为什么可能不适合多模态接触？

**标准答案：** 同一状态下可能有多个可行接触序列，如左推或右推。单峰高斯会把模式平均，生成中间不可行动作。Mixture policy、autoregressive policy、diffusion policy 更适合表达多模态动作。

**评分要点：** 必须说明动作平均导致不可执行。

### Q042. GMM policy 的 log-sum-exp 难点是什么？

**标准答案：** 混合高斯 log probability 为 $\log\sum_k w_k\mathcal{N}_k(a)$，直接计算可能上溢或下溢，需要 log-sum-exp trick。相比单高斯解析 logprob，数值和优化更复杂，还可能出现 mode collapse。

**评分要点：** 必须提到 log-sum-exp 和 mode collapse/数值复杂。

### Q043. SAC 自动温度调节的目标是什么？

**标准答案：** 自动温度调节让 entropy 系数 $\alpha$ 根据实际策略熵与目标熵的偏差更新。熵太低则增大探索，熵太高则降低随机性。它避免手工固定 entropy weight 在不同任务中失效。

**评分要点：** 必须说明 target entropy 闭环。

### Q044. SAC 中双 Q 网络为什么取最小值？

**标准答案：** 函数逼近和 max/actor 优化会造成 Q 过估计，双 Q 取最小值提供保守目标，降低 actor 利用虚高 Q 的风险。代价是可能略保守，但通常显著提升稳定性。

**评分要点：** 必须提到过估计偏差。

### Q045. DDPG 为什么容易在接触任务中不稳定？

**标准答案：** DDPG 使用确定性 actor 和单 critic，容易受 Q 过估计、探索噪声不足和 replay 分布偏移影响。接触任务非光滑、多模态，确定性策略更容易卡在脆弱局部模式。

**评分要点：** 必须提到确定性策略和 Q 不稳定。

### Q046. TD3 的 delayed policy update 为什么有效？

**标准答案：** Critic 学得不稳时频繁更新 actor 会追逐错误 Q 梯度。TD3 让 critic 多更新几步再更新 actor，使策略改进基于更可靠价值估计，减少震荡。

**评分要点：** 必须说明 actor 不要追逐未收敛 critic。

### Q047. Replay buffer 在真实机器人中有什么风险？

**标准答案：** Replay 提高样本效率，但旧数据可能来自不同温度、摩擦、策略和硬件状态，分布不再匹配当前系统。若不记录隐变量或做重加权，off-policy 更新会学到过时动力学。

**评分要点：** 必须提到非平稳真实环境。

### Q048. Offline RL 为什么需要行为策略约束？

**标准答案：** 数据集外动作没有真实回报监督，Q 函数会外推错误。行为约束、保守 Q 或 advantage-weighted regression 把策略限制在数据支持附近，减少 OOD 动作。真机数据昂贵时这是安全前提。

**评分要点：** 必须说明数据支持和 OOD 外推。

### Q049. CQL 与 IQL 的保守性差异是什么？

**标准答案：** CQL 显式压低数据外动作的 Q 值，使学习到的价值保守；IQL 避免对 OOD 动作取 max，使用 expectile value 和 advantage-weighted 行为提取策略。二者都防止外推，但实现路径不同。

**评分要点：** 必须区分压低 OOD Q 和避免 OOD max。

### Q050. Decision Transformer 为什么不是传统值函数 RL？

**标准答案：** DT 把轨迹建模为序列，条件是期望 return，使用 supervised sequence modeling 预测动作。它不显式学习 Bellman backup，而是从数据中学习 return-conditioned 行为。数据质量和覆盖决定其表现。

**评分要点：** 必须提到 return-conditioned sequence modeling。

### Q051. RLPD 为什么适合真实世界 RL？

**标准答案：** RLPD 将演示数据和在线交互数据混合进 replay，演示提供安全初始覆盖，在线数据改进真实任务指标。它兼顾 sample efficiency 和 safe exploration，适合真机早期策略不稳定阶段。

**评分要点：** 必须说明 demo + online replay 的互补。

### Q052. Human-in-the-loop RL 的核心价值是什么？

**标准答案：** 人类可在策略接近失败边界时纠正动作、reset 或提供偏好，补足 reward 稀疏和安全约束不足。它把高风险真机探索变成受监督探索，但需要处理人类延迟和干预分布偏差。

**评分要点：** 必须提到安全纠错和人类延迟/偏差。

### Q053. 为什么 test-time RL 需要强安全边界？

**标准答案：** 部署时在线学习会在真实硬件上尝试新动作，错误探索可能损坏系统。必须用 BC 正则、短 horizon、动作限幅、CBF/LCB filter 和人工急停约束更新，不能像仿真中自由探索。

**评分要点：** 必须说明部署探索风险和安全过滤。

### Q054. Dreamer 类 world model 的核心训练信号是什么？

**标准答案：** 它学习 latent dynamics、reward/continue prediction 和 observation reconstruction 或 representation consistency，在潜空间中 imagined rollout 优化 actor-critic。关键是 latent 是否保留控制相关物理变量，而不是只重建外观。

**评分要点：** 必须提到 latent dynamics 和 imagined rollout。

### Q055. 为什么 world model one-step loss 不能代表控制质量？

**标准答案：** 控制依赖多步闭环预测、关键接触事件和不确定性校准；one-step 平均误差低可能仍在长 horizon 累积偏差，或平均掉多模态未来。应评估 multi-step rollout、planning success 和 OOD 校准。

**评分要点：** 必须提到多步误差和多模态。

### Q056. Ensemble world model 主要估计哪类不确定性？

**标准答案：** 多模型分歧主要近似 epistemic uncertainty，即模型因数据不足而产生的不确定性。它可通过采集数据降低，适合主动学习和安全过滤。环境固有随机性还需分布输出表示 aleatoric uncertainty。

**评分要点：** 必须区分 epistemic 与 aleatoric。

### Q057. Model exploitation 是什么？

**标准答案：** 策略在模型中优化时发现并利用模型错误获得虚假高回报，例如穿透、错误接触或 OOD 动作被模型高估。真实执行会失败。缓解方法包括 ensemble penalty、LCB、BC 正则、短 horizon 和真实数据回填。

**评分要点：** 必须说明利用模型错误和缓解手段。

### Q058. Diffusion policy 为什么适合 imitation 但不天然安全？

**标准答案：** Diffusion 能拟合多模态演示动作分布，减少平均动作问题；但生成的 chunk 可能在当前状态物理不可行，且多步执行期间反馈滞后。真机需要低层控制、安全过滤和不确定性检查。

**评分要点：** 必须同时说明多模态优势和 chunk 风险。

### Q059. Classifier-free guidance 如何影响动作生成？

**标准答案：** CFG 用有条件和无条件去噪得分差放大任务条件影响。Guidance weight 大时更追目标但可能离开自然动作流形；小时时动作自然但任务跟随弱。机器人中需要在可执行性和目标性之间调节。

**评分要点：** 必须说明 guidance weight trade-off。

### Q060. HER 的 hindsight goal 必须满足什么条件？

**标准答案：** 重标目标应是轨迹实际达到且任务 reward 可重新计算的状态，否则会引入虚假成功。对复杂接触任务，还要保证 hindsight goal 与物理过程一致，而不是把危险或仿真伪影轨迹标为好。

**评分要点：** 必须说明可重算 reward 和物理一致性。

### Q061. Curiosity reward 为什么可能引导危险探索？

**标准答案：** 新奇或模型误差大的区域可能是硬件不可执行、接触危险或传感噪声高的区域。若只追 uncertainty，策略会撞击、发热或掉落。需要把信息增益与 actuator/contact feasibility 和 safety filter 结合。

**评分要点：** 必须说明新奇不等于可控。

### Q062. Empowerment 为什么适合作为可控性内在奖励？

**标准答案：** Empowerment 衡量动作对未来状态的影响能力。保持高 empowerment 鼓励机器人留在可控接触和姿态中，避免掉落或失去接触这类低可控状态。它比单纯距离目标更关注控制余地。

**评分要点：** 必须提到动作到未来状态的可控性。

### Q063. DIAYN 学到的 skill 如何迁移到操作任务？

**标准答案：** DIAYN 学习可区分的无监督技能，如推、转、滑、夹等基础行为。下游任务可选择、组合或微调这些技能，减少从零探索。关键是技能要和物理可控模式对应，而不只是视觉状态差异。

**评分要点：** 必须说明技能多样性和物理可用性。

### Q064. POMDP 中 belief state 为什么重要？

**标准答案：** 单帧观测无法包含隐藏接触、摩擦、温度、延迟和物体速度等信息。Belief state 用历史观测推断这些隐变量，使策略在不完全观测下近似马尔可夫。RNN、滤波器和粒子集都可表示 belief。

**评分要点：** 必须提到隐藏变量和历史推断。

### Q065. Kalman filter 与 particle filter 的根本差异是什么？

**标准答案：** Kalman 系列用均值和协方差近似高斯 belief，适合近线性/单峰；particle filter 用样本表示任意分布，适合多峰和接触模式切换，但高维下样本退化严重。

**评分要点：** 必须比较高斯单峰与样本多峰。

### Q066. Itō SDE 中噪声为什么会改变期望动力学？

**标准答案：** Itō 引理包含二阶 Hessian 项，零均值噪声通过非线性函数曲率影响期望变化。因此在非线性接触系统中，传感或动力学噪声可能系统性改变滑移概率和能量，而不只是平均为零。

**评分要点：** 必须提到二阶项和非线性。

### Q067. 为什么随机接触模式适合用 hybrid stochastic process 表示？

**标准答案：** 系统既有连续状态演化，又有离散接触/滑移/分离模式跳变，跳变概率受噪声和动作影响。Hybrid stochastic process 能同时描述连续动力学和随机模式切换，比单一高斯过程更贴近接触现实。

**评分要点：** 必须提到连续状态和离散模式。

### Q068. GPR 不确定性为什么容易在高维失效？

**标准答案：** 高维状态下数据稀疏，核距离度量变差，计算复杂度随样本立方增长，方差可能过度保守或不校准。灵巧操作常用局部 GP、稀疏 GP 或 ensemble neural networks 替代。

**评分要点：** 必须提到维度灾难和计算复杂度。

### Q069. MPPI 为什么适合非光滑系统？

**标准答案：** MPPI 只需要 rollout 成本，不依赖精确梯度，因此能处理接触、碰撞和黑箱仿真。它通过采样探索局部控制分布，但在高维灵巧手动作中样本成本高，需要结构化噪声或低维动作参数化。

**评分要点：** 必须说明无需梯度和高维采样成本。

### Q070. Risk-sensitive RL 与普通期望回报有什么差异？

**标准答案：** 普通 RL 最大化平均回报，可能接受少量灾难失败；risk-sensitive RL 考虑方差、CVaR 或最坏情况，更重视低尾风险。真机安全任务中，避免低概率灾难比提高平均分更重要。

**评分要点：** 必须提到尾部风险。

### Q071. CVaR 在机器人安全中表达什么？

**标准答案：** CVaR 衡量最坏一部分结果的平均损失，例如最差 5% rollout 的温度、碰撞或掉落损失。它能约束尾部风险，避免均值成功率掩盖危险失败。

**评分要点：** 必须说明最坏分位平均。

### Q072. Mutual information 用于主动触摸时的动作选择逻辑是什么？

**标准答案：** 选择预期能最大减少物体形状、位姿或接触参数不确定性的触摸动作，即最大化 $I(X;Y|a)$。动作价值来自它能区分候选 belief，而不只是当前任务奖励。

**评分要点：** 必须说明动作条件下的信息增益。

### Q073. 信息瓶颈为什么能防止表征过拟合？

**标准答案：** 信息瓶颈限制 latent 保留输入中与任务无关的信息，只保留预测控制变量所需内容。它可减少触觉噪声、纹理和传感器个体差异对策略的干扰，但压缩过强会丢失滑移等关键信息。

**评分要点：** 必须说明压缩与控制信息 trade-off。

### Q074. Entropy regularization 和 exploration bonus 有什么区别？

**标准答案：** Entropy regularization 鼓励动作分布随机性，直接作用于策略；exploration bonus 奖励访问新颖或信息量高的状态，作用于状态分布。前者不保证探索有意义，后者需要不确定性或新颖性估计。

**评分要点：** 必须区分动作随机和状态新颖。

### Q075. 为什么随机初始化分布会改变 RL 难度？

**标准答案：** 初始状态决定策略早期能否接触到奖励和关键相位。若从过难状态开始，rollout 全失败没有梯度；从中间成功状态开始可学习后半段。课程学习本质上是在重塑训练状态分布。

**评分要点：** 必须说明初始化影响可学习信号。

### Q076. 为什么 reward normalization 可能改变训练行为？

**标准答案：** 归一化会改变不同 reward 项和时间阶段的相对尺度，影响 advantage 和梯度大小。若成功稀疏项被密集项淹没，策略会优化局部代理；若归一化随时间变化太快，也会造成非平稳目标。

**评分要点：** 必须提到 reward 项相对权重。

### Q077. Advantage normalization 的好处和风险是什么？

**标准答案：** 它稳定梯度尺度，使 PPO 更新不受回报绝对量级影响；但若 batch 内成功样本极少，标准化可能放大噪声或把失败中的相对好坏误当强信号。稀疏高动态任务需结合成功率和 value 诊断。

**评分要点：** 必须说明尺度稳定和小样本噪声风险。

### Q078. 为什么 critic loss 低不一定说明策略好？

**标准答案：** Critic 只拟合当前数据分布上的 returns，若策略分布狭窄或任务奖励设计错误，critic 可低误差但策略仍无效。还可能因为 reward scale 小而 loss 低。应结合成功率、OOD value 校准和策略行为分析。

**评分要点：** 必须说明 critic 是数据分布内评估器。

### Q079. 为什么 actor loss 数值不能直接当性能指标？

**标准答案：** Actor loss 是带 advantage、ratio 和 clipping 的优化目标，数值受标准化、entropy、batch 分布和实现符号影响。训练成功时 actor loss 可能接近零或为负，关键应看策略行为、KL、clip fraction 和成功率。

**评分要点：** 必须说明 loss 数值依赖实现和分布。

### Q080. KL 自适应学习率在 PPO 中起什么作用？

**标准答案：** KL 衡量新旧策略距离；若 KL 太大，降低学习率防止策略崩溃；若 KL 太小，提高学习率避免更新过慢。它是 trust region 思想的工程化调度。

**评分要点：** 必须说明 KL 控制更新幅度。

### Q081. Clip fraction 表示什么？

**标准答案：** Clip fraction 表示 PPO ratio 超出 $[1-\epsilon,1+\epsilon]$ 被裁剪的样本比例。过高说明更新太大或数据分布偏移严重，过低可能说明更新太小。它比 actor loss 更能诊断 PPO 更新健康度。

**评分要点：** 必须提到 ratio 被裁剪比例。

### Q082. 为什么 rollout horizon 影响 credit assignment？

**标准答案：** Horizon 太短看不到延迟奖励和任务后果，value bootstrap 偏差大；太长方差和存储成本高。动态操作中关键结果可能在数百步后出现，horizon 必须覆盖相位因果链。

**评分要点：** 必须说明延迟奖励和方差权衡。

### Q083. Discount factor $\gamma$ 在动态任务中有什么物理含义？

**标准答案：** $\gamma$ 决定未来奖励的有效时间尺度。太低会让策略短视，只优化局部接触或能量；太高会增加估计方差。对转笔等长因果链任务，$\gamma$ 需足够大以看到后续 spin/catch 成功。

**评分要点：** 必须连接 $\gamma$ 与任务时间尺度。

### Q084. 为什么 domain randomization 不能覆盖结构性错误？

**标准答案：** DR 调参数范围，但若仿真缺少真实机制，如 CAN 异步、触觉迟滞、丝杠 stick-slip 或柔性接触，随机化已有参数无法创造正确因果结构。需要模型扩展、系统辨识或在线适应。

**评分要点：** 必须说明参数不确定与结构缺失区别。

### Q085. Online adaptation latent 应该编码什么？

**标准答案：** 应编码影响转移动力学但不可直接观测的隐变量，如摩擦、质量、执行器延迟、温度、触觉偏置和接触刚度。它不应编码任务标签或短期噪声，否则会混淆物理适应与策略记忆。

**评分要点：** 必须列出部署隐变量。

### Q086. 为什么 adaptation 需要历史动作和历史状态？

**标准答案：** 仅看状态无法判断系统为何如此；同样位置可能由不同动作和延迟造成。历史动作-响应序列揭示执行器增益、摩擦和延迟，是辨识动力学隐变量的最小证据。

**评分要点：** 必须说明动作-响应关系。

### Q087. 为什么真机 RL 要记录“失败前”的数据？

**标准答案：** 失败瞬间之后常已不可恢复，但失败前的触觉、动作、温度和状态变化包含早期预警信号。学习恢复和安全过滤需要这些 precursor，而不是只记录成功轨迹或终止状态。

**评分要点：** 必须提到早期失败预警。

### Q088. 为什么 reset policy 可以被看作另一个 goal-conditioned policy？

**标准答案：** Reset 的目标是把当前任意状态带回 home 或安全初始分布，本质是条件目标控制。把 reset 建模为 goal-conditioned/inverse task 可复用同一策略架构和数据，而不是人工写死脚本。

**评分要点：** 必须说明 reset 是目标条件任务。

### Q089. 为什么 safety layer 会改变策略学习分布？

**标准答案：** Safety layer 修改或拒绝策略动作，环境实际执行的动作分布不同于 actor 输出分布。若训练不考虑这一层，策略可能学会依赖过滤器或收到错误 credit assignment。应把 filtered action 记录进 replay。

**评分要点：** 必须提到执行动作与策略动作不一致。

### Q090. 为什么 learned reward 需要校准？

**标准答案：** Learned reward 若过度自信或有偏，会被策略优化放大，产生 reward hacking。需要用真实成功标签、专家偏好、物理约束和 OOD 检测校准，尤其不能把未校准模型直接作为真机唯一奖励。

**评分要点：** 必须说明优化会放大奖励错误。

### Q091. 为什么 RL 中“探索”必须和“可恢复性”绑定？

**标准答案：** 真机探索若进入不可恢复状态会带来人工 reset、硬件损伤和数据中断。可恢复性要求动作即使失败也能通过 recovery policy 或安全网回到训练分布。高信息但不可恢复的动作不应执行。

**评分要点：** 必须提到 recovery 和人工 reset 成本。

### Q092. 为什么 world model 的 observation target 不应只包含 RGB？

**标准答案：** RGB 重建可能学到外观而忽略控制关键变量，如关节响应、触觉、接触状态和执行器温度。Manipulation world model 应预测任务相关状态和物理信号，而不是只让视频好看。

**评分要点：** 必须说明控制相关预测目标。

### Q093. 为什么 contrastive representation 可能适合触觉？

**标准答案：** 触觉存在大量局部噪声和传感器差异，对比学习可通过正负样本把同一接触事件的不同观测拉近、不同接触模式拉远。关键是正负样本定义要反映物理接触，而非随机时间邻近。

**评分要点：** 必须说明物理意义的正负样本。

### Q094. 为什么 token 化不等于压缩一切？

**标准答案：** Token 应保留决策所需的状态、接触和任务信息，而不是盲目降维。过度 token 化会丢失滑移、温度或细粒度动作约束；好的 token 是可被控制和价值函数使用的 sufficient statistic 近似。

**评分要点：** 必须提到决策充分性。

### Q095. 为什么 scaling law 对机器人 RL 难直接套用？

**标准答案：** 机器人数据受物理时间、安全、硬件磨损和 reset 限制，不能像语言数据无限复制。计算更多不一定补足接触/执行器结构性 gap。Scaling 需要同时考虑仿真吞吐、真实数据质量和任务覆盖。

**评分要点：** 必须提到物理数据瓶颈。

### Q096. 为什么 reward-free pretraining 对机器人仍有价值？

**标准答案：** 预训练可学习环境动力学、技能多样性和表征，在后续稀疏任务中减少探索成本。即使没有任务 reward，机器人也能学会推动、抓取、接触、恢复等基础可控模式。

**评分要点：** 必须说明预训练基础技能/动力学。

### Q097. 为什么 off-policy evaluation 在机器人中重要？

**标准答案：** 真实试错昂贵且危险，OPE 试图用已有数据评估新策略风险和收益。由于数据覆盖不足，必须报告不确定区间，而非单点估计。它可作为真机放行前的筛选工具。

**评分要点：** 必须提到真实试错成本和覆盖不足。

### Q098. 为什么 policy evaluation 和 policy improvement 不能混淆？

**标准答案：** Evaluation 估计当前策略或候选策略价值；improvement 根据估计改进策略。若评估误差大却直接改进，策略会放大错误。Unified PE/PI 框架强调采样分布、正则和更新调度必须匹配。

**评分要点：** 必须说明先评估再改进和误差放大。

### Q099. 为什么 RL 题库要考 stochastic process 和 information theory？

**标准答案：** 灵巧操作不是完全可观测确定系统：接触随机、传感噪声、隐藏执行器状态和数据昂贵都需要概率 belief；主动感知、探索和表征压缩需要信息论目标。没有这些基础，RL 只剩调参经验。

**评分要点：** 必须说明不确定性和信息采集是 RL 基础。

### Q100. 请总结本专题的核心主线。

**标准答案：** RL 提供从交互数据中学习策略和值函数的方法，随机过程提供对隐藏状态、噪声和模式切换的建模，信息论提供探索、主动感知和表征选择原则。三者共同服务真机灵巧操作中的安全高效学习。

**评分要点：** 必须完整概括三者分工。
