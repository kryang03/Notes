# Learning to Model the World with Language
> [!abstract] 核心贡献
> 用语言描述作为 WM 的辅助训练信号/条件输入，帮助 WM 学习更语义化的世界表征。

## 与 WMTS 关联
- 语义条件 WM → WMTS 可考虑用任务语义描述条件化 WM 预测
- 语言接口为 WMTS 扩展到 VLA 架构预留路径
- 但灵巧操作的语言描述粒度挑战大（"旋转10°" vs "用力推"）
