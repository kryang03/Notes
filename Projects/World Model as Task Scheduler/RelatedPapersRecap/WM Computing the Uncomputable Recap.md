# World Models: Computing the Uncomputable
> [!abstract] 核心贡献
> 理论视角审视 WM 的计算极限：不完全可观测性 + 有限模型容量 → WM 必然是近似的。讨论何时/为何 WM 足够好。

## 与 WMTS 关联
- **WM 近似性的理论基础**：WMTS 不追求完美 WM → 理论支持
- WM 精度要求与下游任务相关——WMTS 用于 Curiosity + Safety Check，不需要像素精确
- 有限模型容量约束下的 WM 设计策略参考
