# World Models for Dexterous Hand-Object Interaction
> [!abstract] 核心贡献
> 专门为灵巧手-物体交互设计的 WM，处理高维状态、接触丰富场景，用 imagination 加速灵巧操作训练。

## 与 WMTS 关联
- **直接对标** WMTS Ensemble WM 在灵巧手场景的应用
- 接触丰富场景 WM 的误差特征：接触切换时预测跳变——支持 WMTS 物理先验嵌入的必要性
- 高维灵巧手状态（~100D）的 WM 可行性验证
