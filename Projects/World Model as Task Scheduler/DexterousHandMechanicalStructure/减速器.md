# 灵巧手减速器与丝杠

> [!abstract] 本篇在链路中的位置
> 整条链路是 **电能 → 电机电磁力矩 → FOC 电流环 → 减速器/丝杠/连杆 → 关节力矩 → 刚体+接触**。本篇管的是中间那一段：**电机轴上的小力矩、高转速，如何被"换算"成关节需要的大力矩、低转速**——以及这次换算顺带塞进来的三样东西：**背隙 (backlash)、摩擦 (friction)、弹性 (compliance)**。上一篇是 [[电机]]（为什么小电机力矩不够，非得减速不可）；下一篇是 [[传动]]（减速之后的力矩怎么走到关节：连杆 / 腱绳 / 直驱 / QDD / 直线电缸）。真机数值与拟合在 [[LinkerSysId]] 和 [[Transmission2JointDynamics_gap]]。

> [!tip] 读完你应该能回答
> 1. "$\eta<50\%$ 就自锁"这句话是从哪一步推出来的？它和"螺旋升角 < 摩擦角"是不是同一件事？
> 2. L25 四指电缸导程 0.7 mm、等效减速比 $N_{eq}\approx108$，为什么上电后还能用手掰动（可反驱）？如果把滚动体换成滑动螺母，还能吗？拇指为什么掰不动？
> 3. 减速比取多大是"最优"？$i^*=\sqrt{J_L/J_m}$ 这条黄金律从哪来，L25 落在它的哪一侧？
> 4. 谐波减速器"零背隙"，为什么厂商目录仍给一个 lost motion 指标？它对力控意味着什么？
> 5. 拇指那级 17:1 折返减速箱把哪些非理想性"级联"进来了：效率、背隙、折算惯量各按什么规律累积？

## 1. 减速器核心参数

**为什么先讲参数**：后面所有类型的比较，都是在这七个参数上排座次；而对做 RL 真机迁移的人来说，这七个参数每一个都对应一个仿真里"默认为理想"的假设。

| 参数 | 定义（单位） | 对灵巧操作 / sim2real 的影响 |
|-----|------|---------------|
| **减速比 (gear ratio)** $i$ | $i=\omega_{in}/\omega_{out}$（无量纲），理想时 $\tau_{out}=i\,\tau_{in}$ | 越大扭矩放大越多，但**摩擦按 $i^1$、惯量按 $i^2$ 折算到关节**（见下） |
| **背隙 (backlash)** | 正反向切换时的空行程角（arcmin，$1'=1/60°$） | 力矩方向反转时出现**死区**；仿真默认零间隙 |
| **传动效率** $\eta$ | $P_{out}/P_{in}$（无量纲） | 仿真设定的 torque 到真机被吃掉 $(1-\eta)$；正反向 $\eta$ 不对称 |
| **反驱动性 (backdrivability)** | 输出端被外力推动的难易 | 决定被动柔顺与"用电流估力"的可行性；接触安全的前提 |
| **自锁性 (self-locking)** | 外力再大也推不动输出端 | 自锁 = 反驱动性为零；和 $\eta$ 是同一枚硬币（§3.0 推导） |
| **扭矩密度** | 额定扭矩 / 体积或质量（N·m/kg） | 手指内空间以 mm 计 |
| **扭转刚度** $k$ | $\tau/\theta_{tw}$（N·m/rad） | 低刚度 = 关节里藏了一根弹簧；谐波的 $k$ 还是非线性的 |

> [!important] 一句话先立住：摩擦按 $N^1$ 折算，惯量按 $N^2$ 折算
> 设传动比为 $N$（旋转减速器 $N=i$，丝杠电缸 $N=N_{eq}=2\pi R/l$，见 §3.4）。电机侧一份**力矩**（含摩擦力矩）到关节侧被放大 $N$ 倍——这是力的杠杆律；电机侧一份**惯量**到关节侧被放大 $N^2$ 倍——因为动能里速度是平方的（$\tfrac12 J_m\omega_m^2=\tfrac12 (N^2J_m)\omega_j^2$）。所以 $N$ 大到一百量级时，"看起来可忽略"的转子摩擦和转子惯量，在关节侧分别变成 $100\times$ 和 $10^4\times$。完整的能量推导见 [[Actuation#7.2 Reflected Inertia：为什么减速比是把双刃剑|Actuation §7.2]]，两种幂次在真机上分别"买到"什么见 [[Transmission2JointDynamics_gap#2.1 两个不同的幂次|Transmission gap §2.1]]。

> [!note] 减速器摩擦模型 (Stribeck Friction)
> 减速器内部摩擦是非线性的，通常用 **Stribeck 模型**描述：
>
> $$\tau_{friction} = \left[ F_c + (F_s - F_c) \cdot e^{-(\dot{q}/v_s)^2} \right] \cdot \text{sgn}(\dot{q}) + b \dot{q}$$
>
> - $F_c$：库仑摩擦力矩（N·m），滑动时的常值摩擦
> - $F_s$：静摩擦力矩（N·m），$F_s > F_c$，启动要多花一点
> - $v_s$：Stribeck 速度（rad/s），静→动摩擦过渡的特征速度
> - $b$：粘滞系数（N·m·s/rad）
> - $\dot{q}$：关节速度（rad/s）
>
> 仿真里通常只有库仑项（MuJoCo `frictionloss`、Isaac Gym `dof_props['friction']`）加粘滞项（`damping`），**没有 Stribeck 过渡**——这是机械侧 sim2real gap 的一个固定来源（[[Actuation#8.2 三大非理想性——机械侧 gap 的主体|Actuation §8.2]]）。在 L25 上，换向死区的主体是"死区总宽"而非 $F_s/F_c$ 比值，见 [[Transmission2JointDynamics_gap#1.3 主要矛盾：阶梯的主体是死区**总宽**，不是 $F_S/F_C$ **比值**|Transmission gap §1.3]]。

## 2. 旋转-旋转类减速器

**为什么现在讲这个**：机器人关节里绝大多数减速器是"旋转进、旋转出"的。灵巧手手指里能塞下的只有其中两三种，但要理解为什么是这两三种，得把整个谱系过一遍——每种减速器都是在"扭矩密度 / 背隙 / 效率 / 体积"四角里选了一个角。

### 2.1 行星齿轮箱 (Planetary Gearbox)

![[行星减速器.png]]

#### 结构与原理

四个核心部件：

1. **太阳轮 (sun gear)**：中心，由电机驱动 = 输入
2. **行星轮 (planet gear)**：环绕太阳轮，既自转又公转
3. **内齿圈 (ring gear)**：固定的外齿圈，约束行星轮
4. **行星架 (carrier)**：承载行星轮的轴，随公转输出 = 输出

**减速比推导（内齿圈固定）**：用 Willis 相对运动法——站在行星架上看，太阳轮与内齿圈是一对普通齿轮副，转速之比等于齿数反比且反向：
$$\frac{\omega_{sun}-\omega_{carrier}}{\omega_{ring}-\omega_{carrier}}=-\frac{Z_{ring}}{Z_{sun}}$$
令 $\omega_{ring}=0$：$\omega_{sun}-\omega_{c}=\frac{Z_{ring}}{Z_{sun}}\omega_{c}$，于是
$$i=\frac{\omega_{sun}}{\omega_{carrier}}=1+\frac{Z_{ring}}{Z_{sun}}$$
$Z$ 为齿数。单级 $i$ 受"行星轮要装得下"限制（一般 3–10），更大减速比靠**多级串联**：$i=\prod_k i_k$。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **减速比范围** | 单级 3:1–10:1，多级可达 100:1+ |
| **扭矩密度** | **高**（3 个行星轮同时啮合，载荷分散） |
| **紧凑性** | **优秀**（同轴，径向对称） |
| **背隙** | 精密伺服级 ≤3′（高精型 <1′）；经济型 8–15′ 量级（原文档值，待核实）；微型塑料/金属直齿减速箱可达 1–3°（多级累积） |
| **效率** | 高（单级 ≥95–97%，两级 ≈94%） |
| **反驱动性** | **良好**（高效率 → §3.0 的反向效率也高） |
| **噪音** | 中等 |

#### 灵巧手应用

行星箱因紧凑、高扭矩密度广泛用于灵巧手关节模组与 QDD 执行器（MIT Mini Cheetah 用**单级行星 6:1**）。主要问题是**背隙**——在需要频繁换向的精密力控中，背隙就是力矩死区。

### 2.2 斜齿轮箱 (Helical Gearbox)

![[斜齿轮箱.mov]]

#### 结构与原理

斜齿轮的齿面与轴线呈螺旋角 $\beta$（通常 15–30°），啮合是**渐进式**的——任意时刻总有多对齿部分接触（重合度 >1）。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **平滑性** | **极高**（渐进啮合，无冲击） |
| **噪音** | **极低** |
| **承载能力** | 高（多齿同时接触） |
| **轴向力** | 存在（$F_a=F_t\tan\beta$，需推力轴承抵消） |
| **效率** | 高（94–98%） |

#### 局限性

轴向推力增加了轴承设计复杂度，且平行轴布置尺寸较大，不适合手指内部空间。

### 2.3 蜗轮蜗杆减速器 (Worm Gearbox)

![[蜗轮蜗杆减速器.mov]]

#### 结构与原理

蜗杆（螺旋轴）驱动蜗轮（大齿轮）旋转，实现大减速比和 90° 换向。**蜗杆本质上就是一根螺纹**——所以它的自锁与效率分析和 §3.0 的丝杠完全共用一套公式：导程角 $\lambda$ 与摩擦角 $\rho$ 谁大谁赢。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **减速比** | 单级 5:1–100:1 |
| **自锁性** | **强**（$\lambda<\rho$ 时完全自锁，对应 $\eta_{fwd}<50\%$） |
| **反驱动性** | **极差** |
| **背隙** | 低（滑动啮合，间隙小） |
| **效率** | 低（30–90%，取决于导程角；小导程角高减速比时最低） |

> [!warning] 不适合力控应用
> 自锁意味着外力无法反向驱动关节。在灵巧操作中这导致：
> 1. 无被动柔顺（碰撞时关节锁死，冲击全部由结构承受）
> 2. 力感知失效（输出端力矩传不回电机电流，"用电流估力"这条路断了）
> 3. 阻抗控制的"表观惯量地板"无限高（[[ControlTheory#3.2 阻抗控制：调节力与运动的动态关系|阻抗控制]]在带宽外暴露的是物理机构，而自锁机构在带宽外是刚体）
>
> 它的正面价值是**断电保持**——这也是为什么"自锁 vs 反驱"是灵巧手选丝杠型式时的核心取舍（§3.4）。

### 2.4 谐波减速器 (Harmonic Drive)

![[谐波减速器.webp]]

#### 结构与原理

谐波减速器（strain wave gear）基于**弹性变形**原理，只有三个基本部件：

1. **波发生器 (wave generator)**：椭圆凸轮 + 薄壁滚珠轴承 = 输入
2. **柔轮 (flexspline)**：薄壁杯形合金钢件，杯口外齿；径向柔、扭转刚。被波发生器撑成椭圆
3. **刚轮 (circular spline)**：带内齿的刚性环，固定于壳体，比柔轮**多 2 齿**

> [!note] 啮合原理与减速比
> 波发生器转一圈，椭圆长轴两端的柔轮齿与刚轮齿啮合区各扫过一整圈；因为柔轮比刚轮少 2 齿，扫完一圈后柔轮相对刚轮**退回 2 个齿距**。于是输入转 1 圈，输出（柔轮）反向转 $2/Z_{flex}$ 圈：
> $$i=\frac{Z_{flex}}{Z_{circ}-Z_{flex}}=\frac{Z_{flex}}{2}$$
> 长轴两端各有一片啮合区（不是两个点），约 30% 的齿同时传力——这是它扭矩密度高的来源。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **背隙** | **零背隙**（齿面弹性预载，无间隙）——但**有 lost motion / 迟滞**，见下 |
| **减速比** | 单级 30:1–320:1 |
| **扭矩密度** | **极高** |
| **紧凑性** | **极佳**（3 个零件，薄饼式，可空心轴） |
| **精度** | **极高**（重复定位 <1′） |
| **效率** | 中偏高（65–90%，减速比越高、载荷越轻越低） |
| **反驱动性** | **中等偏差**（高减速比 × 柔轮/波发生器摩擦；反向效率仅正向的 60–80%） |
| **刚度** | 非线性、负载相关（下） |

> [!important] "零背隙" ≠ "零空程"：backlash 与 lost motion 的区分
> - **背隙 (backlash)**：齿与齿之间的**几何间隙**，力矩反向时要先走完这段空程才接触。谐波靠弹性预载把它做成零——这是真的。
> - **Lost motion（空程 / 回差）**：厂商在输出端施加 **±4% 额定力矩**，测正反向扭转角之差。它包含两部分：① 柔轮在小力矩下的**弹性扭转**（$\tau/k_0$，此时刚度最低）；② 加载/卸载路径不同的**迟滞** (hysteresis)，来源是齿面微滑和波发生器轴承内摩擦。高精型 lost motion 可到 0.3–1′。
> - 对力控的意义：谐波关节在**力矩过零附近**依然有一段"动了输入、输出不动"的软区，只不过它是**弹性+迟滞**型的、不是几何间隙型的。仿真里用零间隙刚性铰链两个都没建；两者的补偿方法也不同——背隙用死区补偿，迟滞要用 Prandtl–Ishlinskii 一类带记忆的模型（[[Actuation#8.2 三大非理想性——机械侧 gap 的主体|Actuation §8.2]]）。把 lost motion 压得越低，内部预紧越大 → 摩擦、空载启动力矩越大、效率越低——又是一处取舍。

> [!warning] 柔轮疲劳与冲击脆弱性
> 柔轮每转一圈经历两次弯曲应力循环，长期存在疲劳寿命问题。厂商目录额定寿命通常在 7,000–10,000 h 量级（原文档给 8,000–15,000 h，待核实），疲劳薄弱点在齿圈根部、杯壁与杯底过渡处。
>
> **冲击载荷**对柔轮是灾难性的——瞬时齿面应力超过疲劳极限即造成不可逆损伤（"棘轮化 ratcheting"：齿跳过一格）。抓取失败时的冲击就是这种工况。
>
> **精度保持性**：随齿面磨损，传动误差与 lost motion 会逐步增大，寿命后段回差衰退明显——与 RV 的长期精度稳定形成对比。

> [!note] 非线性刚度
> 柔轮弹性变形使扭转刚度是**负载相关**的：
> $$k(\theta_{tw}) = k_0 + k_1 |\theta_{tw}| + k_2 \theta_{tw}^2$$
> $\theta_{tw}$ 为扭转变形角（rad），$k$ 为切线刚度（N·m/rad）。小载荷软、大载荷硬（stiffening）。仿真常取常数 $k_0$ 或干脆刚性——低力矩指令被弹性"吞掉"位移、高力矩下又突然变硬引起二阶振荡，都是这一项。完整的积分形式与迟滞环推导在 [[Actuation#8.2 三大非理想性——机械侧 gap 的主体|Actuation §8.2]]。

#### 灵巧手应用

谐波是**大关节模组**（DLR/HIT Hand II 每指 BLDC + 谐波 1:100 + 同步带 1:1.25，指尖力约 30 N；人形/协作臂腕关节）的首选，搭配[[电机|无框力矩电机]]。但对 L25 这类**指内电缸**式灵巧手，谐波体积仍然放不进手指，丝杠才是主角（§3）。

> [!tip] 空心轴集成优势
> 谐波结构天然支持大直径空心轴，电缆、气管可穿关节内走线。额定输入转速可达 3500–6000 rpm，与无框电机搭配灵活。

### 2.5 摆线针轮减速器 (Cycloidal Gearbox)

![[摆线针轮减速器.mov|摆线针轮减速器]]

#### 结构与原理

偏心输入轴（曲轴）带动摆线轮做**偏心平动+自转**，摆线轮外齿与壳体内的针齿（滚针）啮合。摆线轮齿数 $Z_{cyc}=Z_{pin}-1$，曲轴每转一圈摆线轮相对针齿壳**退回一个齿距**，再经输出销/销孔机构把摆线轮的自转（去掉平动）取出来。

**减速比（针齿壳固定，摆线轮输出）**：
$$i=\frac{Z_{cyc}}{Z_{pin}-Z_{cyc}}=Z_{pin}-1,\qquad \text{输出与输入反向}$$

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **减速比** | 单级 6:1–119:1 |
| **背隙** | **低**（<1′，针齿滚动接触） |
| **效率** | 高（85–95%） |
| **抗冲击** | **极强**（约半数齿同时承载） |
| **反驱动性** | 中等 |
| **紧凑性** | 良好（略逊于谐波） |

### 2.6 RV 减速器 (Rotary Vector Reducer)

![[RV Reducer.mov]]

#### 结构与原理

RV = "正齿轮一级 + 摆线针轮一级"**两级复合**，且第二级的曲轴是**装在输出盘上**的——这一点决定了总减速比不是简单相乘。

1. **第一级 — 正齿轮**：太阳轮（输入，齿数 $Z_{sun}$）驱动 2–3 个行星轮（齿数 $Z_{planet}$），每个行星轮固定在一根**曲轴**上，曲轴由输出盘支承。
2. **第二级 — 摆线针轮**：曲轴偏心带动两片 RV 齿轮（摆线轮，相位差 180° 抵消不平衡力）在固定针齿壳内摆动，针齿数 $Z_{pin}$、摆线轮齿数 $Z_{pin}-1$；摆线轮通过曲轴把自转传给输出盘。

> [!warning] 修正：原文档给的第一级公式 $i_1=Z_{planet}/Z_{sun}$ 不完整
> 原文只写了第一级的齿数比，并把两级当作独立相乘。但曲轴装在输出盘上、跟着输出转，第一级的行星轮转速是**相对输出盘**的相对转速，必须用相对运动法把两级联立。**正确的总减速比是**
> $$i=1+\frac{Z_{planet}}{Z_{sun}}\,Z_{pin}$$
> **推导**：设输入 $\omega_{in}$、输出盘 $\omega_o$、曲轴相对输出盘的自转 $\omega_{cr}$（rad/s）。
> ① 在输出盘坐标系里，太阳轮转速为 $\omega_{in}-\omega_o$，它和行星轮是外啮合齿轮副（反向、齿数反比）：$\omega_{cr}=-\dfrac{Z_{sun}}{Z_{planet}}(\omega_{in}-\omega_o)$。
> ② 同一坐标系里，针齿壳以 $-\omega_o$ 转，摆线轮相对输出盘不转（它通过曲轴/销与输出盘同转）。对摆线副用 Willis 公式 $\dfrac{\omega_{cyc}-\omega_{cr}}{\omega_{shell}-\omega_{cr}}=\dfrac{Z_{pin}}{Z_{pin}-1}$，代入 $\omega_{cyc}=0$、$\omega_{shell}=-\omega_o$：$-\omega_{cr}(Z_{pin}-1)=-Z_{pin}(\omega_o+\omega_{cr})\Rightarrow \omega_o=-\omega_{cr}/Z_{pin}$。
> ③ 联立 ①②：$\omega_o=\dfrac{Z_{sun}}{Z_{planet}Z_{pin}}(\omega_{in}-\omega_o)\Rightarrow \dfrac{\omega_{in}}{\omega_o}=1+\dfrac{Z_{planet}Z_{pin}}{Z_{sun}}$。
> 由推导可见此配置下输出与输入**同向**；原文"输出与输入相反"对应的是"固定输出盘、针齿壳输出"的另一种安装方式（待核实具体型号）。例：$Z_{sun}=12,\ Z_{planet}=36,\ Z_{pin}=40\Rightarrow i=1+3\times40=121$。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **减速比** | 30:1–300:1 |
| **刚度** | **极高**（全钢刚性、多齿承载） |
| **精度** | **极高**（背隙 <1′） |
| **抗冲击** | **极强** |
| **反驱动性** | 差（高减速比 + 双级摩擦） |
| **体积** | 较大 |

#### 典型应用

机械臂大关节（肩/肘/腰）。灵巧手中因体积几乎不用，但它是理解"多级复合减速如何联立"的最好范例。

> [!tip] RV vs 谐波：核心选型逻辑
> - **扭转刚度**：RV 全钢刚性传动，刚度是谐波的数倍到一个数量级
> - **精度保持性**：RV 回差长期稳定；谐波随柔轮磨损衰退
> - **抗冲击**：RV 约为谐波的 2–3 倍
> - **寿命**：RV 通常 15,000–20,000 h+（原文档值，待核实），高于谐波
> - **劣势**：体积大、内孔小、高速输入效率下降
>
> **判据**：额定扭矩 >200 N·m 或频繁冲击 → RV；紧凑走线 + 轻载 → 谐波。

### 2.7 多级正齿轮 / 折返减速箱 (Multi-stage Spur / Offset Gearhead)

**为什么讲这个**：L25 拇指的 `thumb_mcp` / `thumb_cmc_pitch` 在丝杠电缸前面还多了一级 **17:1 折返减速箱**——就是最朴素的"几对小直齿轮串起来、输出轴与输入轴平行错开"的结构。它没有上面任何一种的光环，却是微型执行器里最常见的减速形式（Dynamixel、Pololu 微型金属减速电机、各种舵机都是它），而且**它的非理想性是级联累积的**，值得单独算一遍。

#### 结构与减速比

$n$ 级外啮合直齿轮，每级 $i_k=Z_{out,k}/Z_{in,k}$：
$$i=\prod_{k=1}^{n} i_k,\qquad \text{方向每级反一次}$$
17:1 通常由 2–3 级拼出（例如 $4.25\times4$ 或 $2.5\times2.6\times2.6$，具体齿数待核实）。"折返"指输出轴与输入轴**平行而不同轴**，让电机与丝杠并排放置以缩短总长——拇指空间比四指更逼仄，这是它存在的理由。

#### 三种非理想性的级联规律（推一遍）

设第 $k$ 级效率 $\eta_k$、背隙 $\theta_{b,k}$（在该级输出轴上量）、该级从动轮+轴的惯量 $J_k$。

**① 效率相乘**：功率逐级通过，每级留下 $\eta_k$：
$$\eta=\prod_k\eta_k$$
微型直齿轮单级 $\eta_k\approx0.90$–$0.95$（塑料齿、低精度取下限），三级即 $0.73$–$0.86$，再乘丝杠效率。这是"多一级减速就多一截不可反驱"的第一个来源。

**② 背隙的加权累积**：把所有级的背隙折算到**输出轴**。第 $k$ 级的空程 $\theta_{b,k}$ 出现在它自己的输出轴上，再经过后面各级减速 $\prod_{j>k}i_j$ 被**缩小**：
$$\theta_{b,out}=\sum_{k=1}^{n}\frac{\theta_{b,k}}{\prod_{j>k}i_j}=\theta_{b,n}+\frac{\theta_{b,n-1}}{i_n}+\frac{\theta_{b,n-2}}{i_{n-1}i_n}+\cdots$$
所以**最后一级的背隙几乎决定一切**，前级背隙被后级减速比除掉。设计上因此把精度花在末级；反过来，若把背隙折算到**电机轴**（位置传感器在电机侧时你看到的就是这个），各级要乘以前面的减速比，前级背隙被放大——同一台减速箱，"从电机看"和"从关节看"的死区差 $i$ 倍。L25 的位置反馈在关节侧（8-bit 电位计/磁编码器），所以真机死区就是 $\theta_{b,out}$ 量级。

**③ 折算惯量按 $N^2$ 逐级累加**：从关节侧看，第 $k$ 级零件的惯量被它**下游**的总减速比平方放大：
$$J_{reflected}=J_m\Big(\prod_{k}i_k\Big)^2+\sum_k J_k\Big(\prod_{j>k}i_j\Big)^2$$
电机转子那一项最大（被整个 $i^2$ 放大），中间齿轮次之。L25 拇指电机转子惯量 $1.4\times10^{-10}$ kg·m² 看似比四指的 $1.425\times10^{-7}$ 小三个量级，但 $N_{eq}\approx1424$–$1800$ 是四指的 13–17 倍，平方后 $\approx170$–$280$ 倍——折算到关节反而同量级（数值见 [[LinkerSysId]]）。

**④ 摩擦按 $N^1$ 逐级累加**（与 §1 呼应）：电机侧静摩擦 $F_{s,m}$ 到关节侧是 $N F_{s,m}$（乘以效率损失），$N\sim10^3$ 时，一个微不足道的转子/电刷静摩擦就足以让关节"掰不动"——这正是拇指与四指反驱表现不同的来源之一，另一半来源是 §3.4 的丝杠自锁判据。真机现象见 [[Transmission2JointDynamics_gap#2.4 自锁：为什么拇指掰不动|Transmission gap §2.4]]。

## 3. 旋转-直线类：丝杠家族

**为什么现在讲这个**：上面所有减速器在 L25 这类手指里都装不下。灵巧手（L25、Inspire、PSYONIC Ability、DexLink 等）最常见的"减速器"其实是一根 **3 mm 量级的丝杠**——电机转一圈推杆走一个导程 $l$（0.6–0.7 mm），再经力臂 $R$（≈12 mm）拉动关节。它把"减速"和"旋转→直线变换"合成了一件事，而且它的自锁/反驱判据是本篇最需要说透的推导。

> [!note] 说明
> 严格说这些是运动变换器（旋转↔直线）而非"减速器"，但它们承担的角色与减速器完全相同：放大力、缩小速度、并顺带引入背隙/摩擦/弹性。腱绳手的卷线机构、直线电缸手的推杆都用它们。

### 3.0 螺旋 = 缠在圆柱上的斜面：自锁与效率的完整推导

**直觉**：把螺纹沿中径展开，就是一个斜面。螺母上的载荷 $F$（N，沿轴向）是斜面上要推的物块，丝杠转动相当于把斜面从物块底下"抽走"。推物块上坡 = 正向驱动（电机举起负载）；物块自己下滑 = 反向驱动（外力推动推杆、带着电机转）。物块会不会自己滑下来，只取决于**坡度**和**摩擦**。

**符号**：导程 $l$（m，转一圈推杆前进的距离；单头螺纹 = 螺距）；中径 $d_m$（m）；螺旋升角 (lead angle)
$$\lambda=\arctan\frac{l}{\pi d_m}$$
——展开一圈，斜面水平长 $\pi d_m$、垂直升 $l$。摩擦系数 $\mu$，摩擦角
$$\rho=\arctan\mu$$
——摩擦力与法向力的合力和法线的夹角。

**正向驱动（推物块上坡）的力平衡**：物块受轴向载荷 $F$（向下）、切向推力 $P_{fwd}$（水平）、斜面支反力（与法线夹角 $\rho$，摩擦阻碍上滑）。三力平衡给出
$$P_{fwd}=F\tan(\lambda+\rho)$$
—— 摩擦相当于把坡度"加陡"了 $\rho$。丝杠上的驱动力矩为 $T_{fwd}=P_{fwd}\,d_m/2$：
$$T_{fwd}=\frac{F d_m}{2}\tan(\lambda+\rho)$$

**正向效率**：理想（无摩擦）时 $T_{ideal}=\frac{Fd_m}{2}\tan\lambda$（能量守恒：$T\cdot2\pi=F\cdot l\Rightarrow T=\frac{Fl}{2\pi}=\frac{Fd_m}{2}\tan\lambda$）。于是
$$\eta_{fwd}=\frac{T_{ideal}}{T_{fwd}}=\frac{\tan\lambda}{\tan(\lambda+\rho)}$$

**反向驱动（物块自己下坡）**：现在摩擦阻碍下滑，相当于把坡度"减缓"了 $\rho$。同样做三力平衡（支反力偏向法线另一侧 $\rho$），载荷 $F$ 在扣除摩擦后**还能剩下**推动斜面的切向力
$$P_{rev}=F\tan(\lambda-\rho)$$
- $\lambda>\rho$：$P_{rev}>0$，载荷自己就能把丝杠反推转起来，输出到丝杠轴的反驱力矩为 $T_{rev}=\frac{Fd_m}{2}\tan(\lambda-\rho)$。**可反驱**。
- $\lambda\le\rho$：$P_{rev}\le0$，载荷连摩擦都胜不过，要再加一个**外部**切向力才能动。**无论 $F$ 多大都推不动**（$F$ 越大，摩擦也按同一比例变大，$\tan(\lambda-\rho)$ 的符号不变）——这就是**自锁**。

> [!important] 自锁判据（几何版）
> $$\boxed{\lambda\le\rho\iff\text{自锁}}\qquad\text{即}\qquad \frac{l}{\pi d_m}\le\mu$$
> 它与 $F$ 无关：**自锁是几何和材料的属性，不是载荷的属性**。

**反向效率**：反向时输入是载荷做的功 $F\cdot l$，输出是丝杠轴上的功 $T_{rev}\cdot2\pi$：
$$\eta_{rev}=\frac{T_{rev}\cdot2\pi}{F\,l}=\frac{\tan(\lambda-\rho)}{\tan\lambda}$$

**"$\eta_{fwd}<50\%$ 即自锁"是从哪来的**：小角度下 $\tan x\approx x$（$\lambda,\rho$ 都只有几度，误差 <1%）：
$$\eta_{fwd}\approx\frac{\lambda}{\lambda+\rho}\;\Rightarrow\;\frac{1}{\eta_{fwd}}=1+\frac{\rho}{\lambda},\qquad \eta_{rev}\approx\frac{\lambda-\rho}{\lambda}=1-\frac{\rho}{\lambda}$$
把 $\rho/\lambda$ 消掉：
$$\boxed{\eta_{rev}\approx2-\frac{1}{\eta_{fwd}}}$$
令 $\eta_{rev}=0$（反驱力矩恰好为零 = 自锁临界）得 $\eta_{fwd}=0.5$。所以：
- $\eta_{fwd}=0.5$ ⇔ $\lambda=\rho$ ⇔ 自锁临界；
- $\eta_{fwd}<0.5$ ⇒ $\eta_{rev}<0$ ⇒ 自锁；
- 想要"好反驱"（$\eta_{rev}>0.6$），需要 $\eta_{fwd}>0.71$；$\eta_{fwd}=0.9$ 时 $\eta_{rev}\approx0.89$。

这条关系对**任何**摩擦主导的传动都近似成立（蜗轮蜗杆、多级齿轮的等效效率），不只是丝杠——它是 [[Actuation#8.1 核心参数与类型谱系|Actuation §8.1]] 那句"$\eta<50\%$ 自锁"的出处。也注意它解释了谐波"反向效率只有正向的 60–80%"：$\eta_{fwd}=0.8\Rightarrow\eta_{rev}\approx0.75$，比值 0.94；$\eta_{fwd}=0.7\Rightarrow\eta_{rev}\approx0.57$，比值 0.82。效率越低，正反不对称越严重。

### 3.1 滑动丝杠 (Lead Screw / 梯形丝杠)

螺母与丝杠直接**滑动**接触（梯形/ACME 螺纹，或 3D 打印机常见的 T8）。

| 特性 | 描述 |
|-----|------|
| **摩擦系数** $\mu$ | 钢-青铜 0.10–0.20；钢-POM/PTFE 涂层 0.05–0.10 |
| **效率** | 20–50%（小导程角）到 ~70%（多头大导程） |
| **自锁** | **通常自锁**（单头小导程时 $\lambda\approx3$–$5°<\rho\approx6$–$11°$） |
| **背隙** | 有（螺纹侧隙），可用弹簧防背隙螺母预紧 |
| **成本/体积** | 最低、最小；无循环机构 |

灵巧手里用它的理由只有一个：**断电保持 + 便宜**。代价是完全丧失反驱与被动柔顺——和蜗轮蜗杆同一档。

| 特性 | 描述 |

| **传动效率** | **高**（>90%），滚动摩擦 |

| **反驱动性** | **可反驱动**（$\eta_{rev}\approx2-1/\eta_{fwd}\approx0.89$ 当 $\eta_{fwd}=0.9$） |
| **承载** | 中等（点接触） |
| **背隙** | 有轴向间隙，可双螺母/过盈滚珠预紧到近零 |

### 3.3 行星滚柱丝杠 (Planetary Roller Screw, PRS)

![[行星滚柱丝杠.webp]]
![[滚柱丝杠.png]]

#### 结构与原理

用多根**带螺纹的滚柱**替代滚珠，滚柱像行星轮一样绕丝杠公转，与丝杠、螺母之间是**多条线接触**：

- **丝杠 (A)**：中心多头螺纹轴
- **螺母 (B)**：内螺纹
- **滚柱 (C)**：单头螺纹，两端带小齿轮
- **内齿圈 (E)**：与滚柱小齿轮啮合，保证滚柱不"走偏"、轴线与丝杠平行
- **保持架 (F)**：保证滚柱周向均布

滚柱相对螺母**不轴向移动**（靠齿圈约束），只有丝杠相对螺母有轴向位移——这一点使它可以做得很短。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **承载能力** | **极高**（比同规格滚珠丝杠高 3–5 倍，线接触） |
| **刚度** | **极高** |
| **紧凑性** | 小规格、小导程即可实现大承载；**可以做到 $\phi$2–3 mm**，比滚珠丝杠更易微型化（无回珠管） |
| **效率** | 高（80–90%，略低于滚珠：滚柱与丝杠间有微量滑动分量） |
| **反驱动性** | 可反驱（$\mu\approx0.005$–$0.01$ 量级） |
| **精度** | 极高 |
| **成本** | 高（滚柱螺纹磨削） |

#### 灵巧手应用

微型 PRS 是人形/灵巧手直线电缸的高端选项（大推力 + 小直径）。它与滚珠丝杠在自锁判据上属于**同一类**（滚动、低 $\mu$、可反驱），区别在承载、刚度、微型化能力和价格。

### 3.4 把 L25 的数字代进去：四指可反驱，拇指掰不动

> [!example] L25 四指电缸（[[LinkerSysId]] 给的参数）
> 丝杠导程 $l=0.7$ mm；丝杠中径 $d_m\approx3$ mm（**假设值，待核实**：微型电缸丝杠外径一般 3–4 mm）；关节力臂 $R\approx12$ mm；转子惯量 $J_{rotor}=1.425\times10^{-7}$ kg·m²。
>
> **① 螺旋升角**
> $$\lambda=\arctan\frac{0.7}{\pi\times3}=\arctan(0.0743)\approx4.25°$$
>
> **② 若是滑动螺母**（$\mu\approx0.15$）：$\rho=\arctan0.15\approx8.5°>\lambda$ → **自锁**。$\eta_{fwd}=\tan4.25°/\tan12.75°=0.0743/0.226\approx0.33<0.5$，$\eta_{rev}\approx2-1/0.33<0$，一致。
>
> **③ 若是滚动体**（滚珠或滚柱，$\mu\approx0.005$）：$\rho=\arctan0.005\approx0.29°\ll\lambda$ → **不自锁**。$\eta_{fwd}=\tan4.25°/\tan4.54°=0.0743/0.0794\approx0.94$，$\eta_{rev}=\tan3.96°/\tan4.25°=0.0692/0.0743\approx0.93$。
>
> **④ 等效减速比**（旋转→直线→关节，推导见 [[LinkerSysId]] 与 [[Actuation#7.2 Reflected Inertia：为什么减速比是把双刃剑|Actuation §7.2]]）：
> $$N_{eq}=\frac{2\pi R}{l}=\frac{2\pi\times12}{0.7}\approx108,\qquad J_{armature}=N_{eq}^2J_{rotor}=108^2\times1.425\times10^{-7}\approx1.65\times10^{-3}\ \text{kg·m}^2$$
>
> **结论**：$N_{eq}\approx108$ 看起来"高减速比理应难反驱"，但反驱性由 $\lambda$ vs $\rho$ 决定、与 $N_{eq}$ 无关；只要丝杠是滚动体型式，$\eta_{rev}\approx0.93$，上电后用手掰得动——与真机观察"无明显自锁"一致。**但这个结论依赖丝杠型式**：L25 的丝杠是滚珠还是滚柱**待核实**（三份文档说法不一），两者结论相同；若是滑动丝杠则结论反转。

> [!example] L25 拇指（`thumb_mcp` / `thumb_cmc_pitch`）
> 导程 $l=0.6$ mm、前置 **17:1 折返减速箱**、转子惯量 $1.4\times10^{-10}$ kg·m²、$N_{eq}\approx1424/1800$。
>
> - 丝杠本身：$\lambda=\arctan\frac{0.6}{\pi\times3}\approx3.6°$（同样取 $d_m\approx3$ mm），若滚动体则仍 $>\rho$，丝杠这一级**本身不自锁**。
> - 但总反驱要穿过整条链：$\eta_{rev,total}\approx\eta_{rev,screw}\times\prod_k\eta_{rev,k}$（§2.7 ①），三级微型直齿各 0.9 → $0.93\times0.73\approx0.68$，仍 >0，理论上不自锁；
> - 真正让它"掰不动"的是 **§2.7 ④ 的 $N^1$ 摩擦折算**：电机侧静摩擦 + 减速箱各级静摩擦一起乘以 $N_{eq}\sim1.4$–$1.8\times10^3$，折算到关节的静摩擦力矩已超过手指能施加的力矩——**不是几何自锁，是"摩擦被放大到你推不动"**。两者对 RL 的含义不同：前者与载荷无关、永远推不动；后者是一个可被大外力突破、但会带来巨大换向死区的高静摩擦关节。真机现象与数据见 [[Transmission2JointDynamics_gap#2.4 自锁：为什么拇指掰不动|Transmission gap §2.4]]。

### 4.2 减速比取多大？惯量匹配最优减速比的推导

**为什么讲这个**：前面都在说"减速比大 → 力矩大但惯量按平方涨"，那到底取多大？存在一个使**关节加速度最大**的减速比，它给了我们评判 L25 的 $N_{eq}\approx108$ 落在哪一侧的标尺。

**设定**：电机转子惯量 $J_m$（kg·m²）、电机力矩 $\tau_m$（N·m）、减速比 $i$、关节侧负载惯量 $J_L$（手指连杆 + 被操作物折算，kg·m²），忽略摩擦与齿轮惯量。

**关节侧动力学**：关节力矩 $i\tau_m$，关节侧总惯量 = 负载 + 折算转子 $=J_L+i^2J_m$（§1 的 $N^2$ 律）：
$$\ddot\theta_L=\frac{i\,\tau_m}{J_L+i^2J_m}$$

**对 $i$ 求极值**：
$$\frac{d}{di}\left[\frac{i}{J_L+i^2J_m}\right]=\frac{(J_L+i^2J_m)-i\cdot2iJ_m}{(J_L+i^2J_m)^2}=\frac{J_L-i^2J_m}{(J_L+i^2J_m)^2}=0$$
$$\boxed{i^*=\sqrt{\frac{J_L}{J_m}}}\qquad\Longleftrightarrow\qquad i^{*2}J_m=J_L$$

**物理解读**：最优点恰是"折算转子惯量 = 负载惯量"——**惯量匹配 (inertia matching / impedance matching)**，与电路里"源内阻 = 负载电阻时功率传递最大"是同一件事。此时关节侧惯量的一半来自电机自己。

- $i<i^*$：**欠减速**——电机"推不动"负载，加速度受力矩限制；
- $i>i^*$：**过减速**——关节侧惯量被转子主导，加速度反而下降，且 $J_{reflected}$ 抬高了阻抗控制在带宽外暴露的物理惯量地板（[[Actuation#7.2 Reflected Inertia：为什么减速比是把双刃剑|Actuation §7.2]]、[[ControlTheory#3.2 阻抗控制：调节力与运动的动态关系|阻抗控制]]）。
- 工程手册说的"负载/电机惯量比 $J_L/(i^2J_m)\le5$–$10$"是这个最优点周围的一个宽容带。

> [!example] L25 落在哪一侧
> 一根手指连杆的惯量量级：质量 ~10 g、长 ~40 mm 的杆绕端点 $J_L\approx mL^2/3\approx5\times10^{-6}$ kg·m²；握着 100 g 物体时可到 $10^{-4}$ 量级（**估算，待核实**）。
> $$i^*=\sqrt{\frac{5\times10^{-6}\sim10^{-4}}{1.425\times10^{-7}}}\approx6\sim26\ \ll\ N_{eq}\approx108$$
> 即 L25 四指处于**深度过减速**区（折算惯量 $1.65\times10^{-3}$ 比连杆本体大 1–3 个量级），拇指更甚。设计者用加速度和反驱带宽换取了**推力密度和体积**——这是所有丝杠电缸手（Inspire、Ability、L25）的共同取舍。对 RL 的意义：这类手的关节动力学被转子惯量主导，`armature` 不填就是漏掉主项（[[Actuator2RigidDynamicsModel_gap]]）；而 QDD（Mini Cheetah $i=6$）恰在 $i^*$ 附近，所以能做接触丰富的高动态任务。

### 4.3 效率、反向效率与"能不能用电流估力"

把 §3.0 和 §2.7 合起来，一台执行器"从关节看"的静态力矩关系是
$$\tau_{joint}=\eta_{fwd}\,N\,\tau_m\ (\text{正向}),\qquad \tau_m^{felt}=\eta_{rev}\,\tau_{ext}/N\ (\text{反向，}\ \eta_{rev}\approx2-1/\eta_{fwd})$$
"用电机电流估关节外力"（无力矩传感器的力控前提）要求 $\eta_{rev}$ 足够大且**稳定**；$\eta_{fwd}$ 每降 10%，$\eta_{rev}$ 降得更多且越来越依赖润滑/温度。这是为什么 [[Actuation#8.2 三大非理想性——机械侧 gap 的主体|Actuation §8.2]] 强调方向相关效率模型。

### 4.4 典型机器人关节减速器配置

> [!example] 6 轴工业机器人经典分工
> | 轴号 | 功能 | 减速器 | 核心理由 |
> |------|------|--------|--------|
> | J1–J3 | 腰/大臂/小臂 | **RV** | 重载、高刚度、抗冲击、长寿命 |
> | J4–J6 | 腕部旋转/弯曲/末端 | **谐波** | 轻量化、紧凑、空心轴走线、高精度 |
>
> 越靠近基座载荷越大 → 刚度与寿命优先（RV）；越靠近末端 → 紧凑与精度优先（谐波）。**再往末端到灵巧手**：关节模组式手（DLR/HIT）用谐波/行星；指内电缸式手（L25/Inspire/Ability）用**丝杠（+ 微型折返减速箱）**；追求接触带宽的 QDD 手用单级行星。

### 4.5 影响 Sim-to-Real 的关键特性

> [!warning] 对仿真建模的影响
> 减速器/丝杠的以下非理想特性是 [[sim2real|Sim-to-Real gap]] 的机械侧主体：
> 1. **背隙 / lost motion**：仿真为零间隙刚性铰链；真机换向有死区（几何背隙）或弹性+迟滞软区（谐波）。L25 上表现为位置阶梯（[[Transmission2JointDynamics_gap]]）
> 2. **非线性摩擦**：Stribeck 过渡、按 $N^1$ 折算后的巨大静摩擦；仿真只有库仑 + 粘滞
> 3. **柔度/扭转弹性**：谐波柔轮非线性刚度与迟滞环；仿真常刚性
> 4. **效率损耗与方向不对称**：$\tau_{out}=\eta_{fwd}\,N\,\tau_m$，反向 $\eta_{rev}\approx2-1/\eta_{fwd}$；仿真 $\eta\equiv1$
> 5. **折算惯量**：$N^2J_m$ 必须进 `armature`，否则关节过轻、增益迁移即振荡
> 6. **温度漂移**：润滑粘度、预紧随温度变，$\mu$ 与 $\eta$ 跟着漂
>
> 每一条对应的仿真参数与 DR 建议见 [[MuJoCo_Sim2Real_Params]] 与 [[Actuation#9.3 按传动方案的 Domain Randomization 建议|Actuation §9.3]]。

## 回扣与承接

用 L25 的一根手指把本篇串一遍：**空心杯电机 → 丝杠电缸 → 连杆 → 关节**。

1. 空心杯电机（[[电机]]）转子惯量只有 $1.425\times10^{-7}$ kg·m²、力矩只有 mN·m 级——**§1**：它必须被减速，而减速会把摩擦 $\times N$、惯量 $\times N^2$ 带到关节。
2. 手指里放不下 **§2** 的任何一种旋转减速器；谐波留给 DLR/HIT 那种关节模组，行星留给 QDD。
3. 于是用 **§3** 的丝杠：导程 0.7 mm、中径约 3 mm → $\lambda\approx4.25°$；只要滚动体（$\mu\approx0.005$，$\rho\approx0.3°$）就不自锁、$\eta_{rev}\approx0.93$ → 上电可反驱。经力臂 12 mm，$N_{eq}\approx108$、`armature`$\approx1.65\times10^{-3}$ kg·m²。
4. 拇指多一级 **§2.7** 的 17:1 折返减速箱：效率相乘、末级背隙主导、$N_{eq}\to1424$–$1800$、静摩擦 $\times N$ 后"掰不动"——不是几何自锁，是摩擦放大。
5. **§4.2** 告诉你 $i^*\approx6$–$26\ll108$：这只手是为推力密度设计的，不是为加速度或接触带宽设计的——这决定了它适合什么任务、以及仿真里哪一项参数（`armature`、frictionloss）是主项。

**下一篇去哪**：
- 减速后的力矩怎么沿连杆走到关节、$N_{eq}(\theta)=2\pi r(\theta)/l$ 为什么随构型变 → [[传动]]
- 数字怎么算、`armature` 怎么填 → [[LinkerSysId]]
- 换向死区实测与拟合、mjlab/Isaac 落地 → [[Transmission2JointDynamics_gap]]

## 对开发与科研的启示

1. **先核实丝杠型式再做任何反驱假设**。§3.4 的全部结论在"滚珠/滚柱"下成立、在"滑动"下反转；这意味着下一步可以做：拆一只备用电缸或查 CAD/供应商 BOM，把"待核实"改成事实，并据此决定仿真里 `frictionloss` 的量级和是否需要建方向相关效率。
2. **拇指与四指要分开建模**。拇指多一级 17:1 意味着效率级联、末级背隙主导、$N^2$ 惯量与 $N^1$ 摩擦都比四指大一个量级；这意味着下一步可以做：在 mjlab 里给拇指关节单独的 `armature` / `frictionloss` / 死区参数组，并在 DR 时对拇指用更宽的摩擦范围。
3. **L25 处于深度过减速区（$N_{eq}\gg i^*$）**，接触瞬间暴露的是 $1.65\times10^{-3}$ kg·m² 的折算惯量而非连杆本体；这意味着下一步可以做：在 WMTS 的 actuator-side 世界模型里显式把 `armature` 作为已知先验而不是待学量，把学习容量留给摩擦与死区这种真正未知的项；同时对高动态接触任务（DNPM 转笔）评估 L25 的接触带宽上限。
4. **反向效率 $\eta_{rev}\approx2-1/\eta_{fwd}$ 是一个可辨识的标量**。这意味着下一步可以做：用"外力推关节、读电流"的静态实验直接拟合 $\eta_{rev}$，与 §3.4 的 0.93 预测对账——若实测明显更低，说明摩擦模型里缺了减速箱/密封/润滑项，而不是丝杠本身。
