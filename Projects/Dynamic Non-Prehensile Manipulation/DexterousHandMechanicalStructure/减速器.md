# 灵巧手减速器

> [!abstract] 概述
> 齿轮箱/减速器 (Gearbox / Speed Reducer) 是一种包含齿轮 (Gears)、传动轴 (Shafts) 和轴承 (Bearings) 的机械减速装置，在灵巧手中承担**增大扭矩**、**降低转速**与**改变传动方向**的核心功能。电机在小尺寸下输出扭矩有限，减速器是弥补扭矩缺口的关键环节。减速器的选型直接影响灵巧手的**背隙 (Backlash)**、**反驱动性 (Backdrivability)**、**柔顺性**和 [[sim2real|Sim-to-Real Gap]]。

---

## 1. 减速器核心参数

在详细讨论各类型之前，先明确减速器选型中的关键参数：

| 参数 | 定义 | 对灵巧操作的影响 |
|-----|------|---------------|
| **减速比 (Gear Ratio)** $i$ | 输入转速/输出转速 | 越大则扭矩放大越大，但响应越慢 |
| **背隙 (Backlash)** | 正反向传动切换时的空行程角度 | 直接导致位置控制死区，影响精密操作 |
| **传动效率** $\eta$ | 输出功率/输入功率 | 影响能耗和力矩估计精度 |
| **反驱动性 (Backdrivability)** | 输出端被外力驱动的能力 | 决定被动柔顺性，对安全接触关键 |
| **扭矩密度** | 额定扭矩/体积或重量 | 灵巧手空间极为紧凑 |
| **自锁性 (Self-locking)** | 反向驱动是否被摩擦锁定 | 自锁减速器不可反驱动，不适合力控 |
| **刚度 (Torsional Stiffness)** | 扭转刚度，影响位置精度 | 低刚度引入弹性变形，增大力控难度 |

> [!tip] 反驱动性与自锁性的关系
> 传动效率 $\eta$ 与自锁条件密切相关。当 $\eta < 50\%$ 时，摩擦耗散超过可传递能量，系统自锁（如蜗轮蜗杆）。灵巧手力控应用需要 $\eta > 50\%$，最好 $> 80\%$，以确保良好的反驱动性。

> [!note] 减速器摩擦模型 (Stribeck Friction)
> 减速器内部的摩擦行为是非线性的，通常用 **Stribeck 摩擦模型**描述：
>
> $$\tau_{friction} = \left[ F_c + (F_s - F_c) \cdot e^{-(\dot{q}/v_s)^2} \right] \cdot \text{sgn}(\dot{q}) + b \dot{q}$$
>
> 其中：
> - $F_c$：库仑摩擦力矩（动摩擦，与速度方向相关）
> - $F_s$：静摩擦力矩（$F_s > F_c$，启动时摩擦更大）
> - $v_s$：Stribeck 速度（静→动摩擦过渡速度）
> - $b$：粘滞摩擦系数
> - $\dot{q}$：关节速度
>
> 在仿真中通常简化为 $\tau_{friction} = F_c \cdot \text{sgn}(\dot{q}) + b\dot{q}$，忽略了 Stribeck 效应——这是 Sim-to-Real Gap 的重要来源之一。

## 2. 旋转-旋转类减速器

### 2.1 行星齿轮箱 (Planetary Gearbox)

![[行星减速器.png]]

#### 结构与原理

行星齿轮箱由四个核心部件组成：

1. **太阳齿轮 (Sun Gear)**：位于中心，由电机驱动，即输入轴
2. **行星齿轮 (Planetary Gear)**：围绕太阳齿轮分布，同时自转和公转
3. **环齿轮 (Ring Gear)**：固定不动的外齿圈，约束行星齿轮运动
4. **行星臂架 (Carrier)**：承载行星齿轮，即输出轴

太阳齿轮被电机驱动旋转，带动行星齿轮在固定环齿轮内部既自转又公转。行星臂架随着行星齿轮的公转而旋转输出。

$$
i = 1 + \frac{Z_{ring}}{Z_{sun}}
$$

其中 $Z$ 是齿数。多级串联可实现更大减速比。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **减速比范围** | 单级 3:1–10:1，多级可达 100:1+ |
| **扭矩密度** | **高**（多齿同时啮合，载荷分散） |
| **紧凑性** | **优秀**（同轴设计，径向对称） |
| **背隙** | 中等（标准行星约 8–15 arcmin，精密型 < 3 arcmin） |
| **效率** | 高（单级 95–97%） |
| **反驱动性** | **良好**（高效率保证） |
| **噪音** | 中等 |

#### 灵巧手应用

行星齿轮箱因紧凑和高扭矩密度广泛用于灵巧手关节模组。但其**背隙**是主要问题——在需要精密力控的灵巧操作中，背隙会导致力矩死区。

### 2.2 斜齿轮箱 (Helical Gearbox)

![[斜齿轮箱.mov]]

#### 结构与原理

斜齿轮的齿面与轴线呈一定螺旋角（通常 15–30°），使得齿面啮合是**渐进式**的——在任意时刻总有多对齿同时接触。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **平滑性** | **极高**（渐进啮合，无冲击） |
| **噪音** | **极低** |
| **承载能力** | 高（多齿同时接触） |
| **轴向力** | 存在（需推力轴承抵消） |
| **效率** | 高（94–98%） |

#### 局限性

轴向推力增加了轴承设计复杂度，且尺寸较大，不适合灵巧手关节内部空间。

---

### 2.3 蜗轮蜗杆减速器 (Worm Gearbox)

![[蜗轮蜗杆减速器.mov]]

#### 结构与原理

蜗杆（螺旋轴）驱动蜗轮（大齿轮）旋转，实现大减速比和 90° 传动方向改变。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **减速比** | 单级可达 5:1–100:1 |
| **自锁性** | **强**（$\eta < 50\%$ 时完全自锁） |
| **反驱动性** | **极差**（自锁导致无法反驱动） |
| **背隙** | 低（滑动啮合，间隙小） |
| **效率** | 低（30–90%，取决于导程角） |

> [!warning] 不适合力控应用
> 蜗轮蜗杆的自锁特性意味着外力无法反向驱动关节。在灵巧操作场景中，这导致：
> 1. 无法实现被动柔顺（碰撞时关节锁死）
> 2. 力感知困难（输出端力矩无法传递到电机电流）
> 3. 完全不适合需要力控的灵巧操作

### 2.4 谐波减速器 (Harmonic Drive)

![[谐波减速器.webp]]

#### 结构与原理

谐波减速器基于**金属弹性力学**的独特原理，仅由三个基本部件组成：

1. **波发生器 (Wave Generator)**：椭圆凸轮上安装薄壁滚珠轴承，作为输入，连接电机轴
2. **柔轮 (Flexspline)**：合金钢制薄壁圆柱杯，杯口端外齿。径向柔顺但扭转刚性极高。波发生器嵌入后使柔轮变形为椭圆
3. **钢轮 (Circular Spline)**：带内齿的刚性环，固定于壳体。比柔轮多 2 个齿

> [!note] 啮合原理
> 波发生器旋转一周，柔轮因弹性变形在钢轮内"蠕动"前进。由于齿数差为 2，电机旋转 $N$ 圈时输出仅旋转 $\frac{2}{Z_{flex}}$ 圈（$Z_{flex}$ 为柔轮齿数），实现极大减速比。数学上，内接椭圆与同心圆在两个区域接触（而非两个点），形成两个啮合区域，同时传递载荷。

$$
i = \frac{Z_{flex}}{Z_{circ} - Z_{flex}} = \frac{Z_{flex}}{2}
$$

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **背隙** | **zero — 零背隙**（弹性预载消除间隙） |
| **减速比** | 单级 30:1–320:1（极高） |
| **扭矩密度** | **极高**（多齿同时啮合，约 30% 齿在传力） |
| **紧凑性** | **极佳**（仅 3 个零件，薄饼式） |
| **精度** | **极高**（重复定位精度 < 1 arcmin） |
| **效率** | 中偏高（65–90%，取决于减速比） |
| **反驱动性** | **中等偏差**（高减速比+柔轮摩擦） |
| **刚度** | 非线性（柔轮弹性变形引入扭转柔度） |

> [!warning] 柔轮疲劳与冲击脆弱性
> 柔轮在工作中持续弹性变形，每转一圈经历数百次弯曲应力循环，长期运行存在疲劳寿命问题。典型设计寿命约 8,000–15,000 小时（额定工况），疲劳薄弱点集中在齿圈底部、内壁前端和筒底。
>
> **冲击载荷**对柔轮是灾难性的——瞬间冲击可使齿面应力超过材料疲劳极限，造成不可逆损伤。在存在碰撞风险的场合（如灵巧手抓取失败时的冲击），需格外注意。
>
> **精度保持性**：随柔轮齿面磨损和弹性模量累积变化，传动误差会随使用时间逐步增大。在寿命后段，回差精度衰退明显——这与 RV 减速器的长期精度稳定性形成鲜明对比。

> [!note] 谐波减速器的非线性刚度特性
> 柔轮的弹性变形导致扭转刚度是**负载相关**的非线性函数。空载时刚度较低，随载荷增大逐渐硬化，可表示为：
> $$k(\theta) = k_0 + k_1 |\theta| + k_2 \theta^2$$
> 其中 $\theta$ 为扭转变形角。这种非线性刚度在仿真中通常被简化为常数 $k_0$，导致仿真器中的关节刚度响应与真实系统不一致。此外，柔轮的迟滞特性（加载与卸载路径不同）进一步增加了建模难度。

#### 灵巧手应用

谐波减速器是当前高端灵巧手关节的**首选减速方案**（尤其搭配[[电机#3. 无框力矩电机 (Frameless Torque Motor)|无框力矩电机]]），因其零背隙、极高扭矩密度和紧凑尺寸。但其**非线性刚度**和**有限反驱动性**对仿真建模和 Sim-to-Real 迁移构成挑战。

> [!tip] 空心轴集成优势
> 谐波减速器结构天然支持大直径空心轴设计，内孔可贯穿电缆、气管等管路，实现关节模组**内走线**。这对协作机器人和人形机器人关节是无可替代的集成优势。额定输入转速通常可达 3500–6000 rpm，与无框力矩电机的搭配灵活度极高。

### 2.5 摆线针轮减速器 (Cycloidal Gearbox)

![[摆线针轮减速器.mov|摆线针轮减速器]]

#### 结构与原理

偏心输入轴驱动摆线轮做偏心旋转（摆动），摆线轮外齿与壳体内针齿啮合。由于摆线轮齿数比针齿少 1（或 2），每次摆动摆线轮前进一个齿距，通过输出机构（销轮/销孔）将低频旋转输出。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **减速比** | 单级 6:1–119:1 |
| **背隙** | **低**（< 1 arcmin，滚动接触） |
| **效率** | 高（85–95%） |
| **抗冲击** | **极强**（多齿同时承载） |
| **反驱动性** | 中等 |
| **紧凑性** | 良好（但略逊于谐波） |

### 2.6 RV 减速器 (Rotary Vector Reducer)

![[RV Reducer.mov]]

#### 结构与原理

RV 减速是"行星齿轮 + 摆线针轮"**两级复合**减速：

1. **第一级 — 正齿轮变速**：太阳轮驱动行星轮，初步降速

$$
i_1 = \frac{Z_{planet}}{Z_{sun}}
$$

2. **第二级 — 差动摆线变速**：行星轮带动曲轴旋转，曲轴上偏心安装两片 RV 齿轮（相位差 180°抵消振动）。RV 齿轮在固定针齿壳内摆动，通过针齿销逐齿推进

$$
\text{针轮偏移角} = \frac{1}{Z_{needle}} \times 360°, \quad Z_{needle} - Z_{RV} = 1
$$

输出方向与输入相反。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **减速比** | 通常 30:1–300:1 |
| **刚度** | **极高**（两级复合，多齿承载） |
| **精度** | **极高**（背隙 < 1 arcmin） |
| **抗冲击** | **极强** |
| **反驱动性** | 差（高减速比 + 双级摩擦） |
| **体积** | 较大（两级结构） |

#### 典型应用

RV 减速器主要用于机械臂大关节（肩/肘/腰），在灵巧手中因体积过大而较少使用，但其设计原理提供了理解多级复合减速的参考。

> [!tip] RV vs 谐波：核心选型逻辑
> - **扭转刚度**: RV 的全钢刚性传动使扭转刚度达谐波方案的**数倍至数量级**
> - **精度保持性**: RV 回差精度长期稳定，不似谐波随柔轮磨损衰退
> - **抗冲击**: 钢制摆线针轮多齿分担载荷，抗冲击性能为谐波的 2–3 倍
> - **使用寿命**: RV 通常 15,000–20,000h+，显著超过谐波 8,000–15,000h
> - **劣势**: 体积大、内孔小（走线困难）、高速输入效率下降
>
> **判据**: 额定扭矩 > 200 Nm 或频繁冲击→RV；紧凑走线+轻载→谐波

## 3. 旋转-直线类减速/变换器

> [!note] 说明
> 以下机构严格来说是运动变换器（旋转↔直线），而非传统意义上的"减速器"。但在灵巧手中，腱绳传动系统的卷线机构、以及一些线性驱动关节的设计会用到它们。

### 3.1 滚珠丝杠 (Ball Screw)

![[滚珠丝杠.png]]

#### 结构与原理

丝杠轴上加工有螺旋凹槽（通常为哥特式拱形截面，**4 个接触点**保证全方向承载），螺母内通过循环滚珠将旋转运动转化为直线运动。

![[滚珠.png]]

- **导程 (Lead)**：螺母在丝杠旋转一圈内移动的距离

![[导程.png]]

> [!note] 导程与性能
> 导程越大 → 直线速度越快，但负载角越陡、承载能力降低、制动力减弱。
> 导程越小 → 精度越高、承载越大，但速度降低。

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **传动效率** | **高** (> 90%)，滚动摩擦替代滑动摩擦 |
| **精度** | 高（精密研磨型可达微米级） |
| **反驱动性** | **可反驱动**（高效率，无自锁） |
| **承载** | 中等 |
| **寿命** | 长（滚珠循环分散磨损） |

---

### 3.2 行星滚柱丝杠 (Planetary Roller Screw, PRS)

![[行星滚柱丝杠.webp]]
![[滚柱丝杠.png]]

#### 结构与原理

用多个螺纹滚柱替代滚珠，通过滚柱（单头螺纹）与丝杠、螺母之间的**多点线接触**传递功率：

- **丝杠 (A)**：中心螺纹轴
- **螺母 (B)**：外部带内螺纹
- **滚柱 (C)**：单头螺纹，两端有小齿轮
- **内齿圈 (E)**：与小齿轮啮合，保证滚柱轴线与丝杠平行
- **保持架 (F)**：保证滚柱均匀分布

#### 核心特性

| 特性 | 描述 |
|-----|------|
| **承载能力** | **极高**（比滚珠丝杠高 3–5 倍，多点线接触） |
| **刚度** | **极高**（多滚柱同时承载） |
| **紧凑性** | 小规格、小导程即可实现大承载 |
| **精度** | 极高 |
| **成本** | 高（加工复杂） |

#### 灵巧手应用

行星滚柱丝杠在一些线性驱动灵巧手设计中用于将电机旋转转为腱绳直线拉力，其高承载和紧凑性是核心优势。

## 4. 灵巧手减速器选型总结

### 4.1 综合对比

| 减速器类型 | 背隙 | 效率 | 反驱动性 | 紧凑性 | 扭矩密度 | 灵巧手适用度 |
|-----------|------|------|---------|-------|---------|-----------|
| **行星齿轮** | 中 | 高 | 良好 | 优 | 高 | ⭐⭐⭐⭐ |
| **斜齿轮** | 中 | 高 | 良好 | 差 | 中 | ⭐⭐ |
| **蜗轮蜗杆** | 低 | 低 | **不可** | 中 | 中 | ⭐ |
| **谐波** | **零** | 中偏高 | 中偏差 | **极优** | **极高** | ⭐⭐⭐⭐⭐ |
| **摆线针轮** | 低 | 高 | 中 | 良好 | 高 | ⭐⭐⭐ |
| **RV** | 极低 | 中 | 差 | 差 | 极高 | ⭐⭐ |

### 4.2 典型机器人关节减速器配置

> [!example] 6 轴工业机器人经典分工
> | 轴号 | 功能 | 减速器 | 核心理由 |
> |------|------|--------|--------|
> | J1–J3 | 腰/大臂/小臂 | **RV** | 重载、高刚度、抗冲击、长寿命 |
> | J4–J6 | 腕部旋转/弯曲/末端 | **谐波** | 轻量化、紧凑、空心轴走线、高精度 |
>
> **选型逻辑**: 越靠近基座→综合载荷越大→刚度和寿命优先 (RV)；越靠近末端→载荷越轻→紧凑性和精度优先 (谐波)。灵巧手关节因尺寸限制，几乎全部采用谐波或行星方案。

### 4.3 影响 Sim-to-Real 的关键特性

> [!warning] 对仿真建模的影响
> 减速器的以下非理想特性是造成 [[sim2real|Sim-to-Real Gap]] 的重要来源：
> 1. **背隙 (Backlash)**：仿真中通常建模为理想关节（零间隙），但实际减速器的背隙导致力矩传递存在死区，位置控制出现抖动
> 2. **非线性摩擦**：静摩擦→动摩擦的 Stribeck 效应、速度相关粘滞摩擦（见上文摩擦模型）
> 3. **柔度/扭转弹性**：谐波减速器柔轮的非线性刚度——仿真中常简化为刚性关节
> 4. **效率损耗**：仿真中设定的 torque 在实机中会被减速器摩擦消耗（$\tau_{out} = \eta \cdot i \cdot \tau_{motor}$）
> 5. **温度漂移**：减速器效率和摩擦特性随温度变化，长时间运行后性能偏移
>
> 详见 [[sim2real|Sim-to-Real Gap 完整分析]]。
