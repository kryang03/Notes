
| **结构方案** | **驱动与传动原理**                            | **核心设计特点**                                                                                                         |
| -------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **连杆结构** | 电机驱动通过减速机构（齿轮、蜗轮等）转化为连杆运动，再传至指关节 。     | 采用刚性连杆与转动副(Revolute Pair，指**两个构件（Link）直接接触并能产生一定相对运动的连接**，转动副仅保留 1 个绕特定轴线相对旋转的自由度)，传动直接且结构简单 ；抓取力与刚度较高，模块化设计易于维护 。 |
| **腱绳结构** | 仿生肌腱传动，电机通过滑轮/绕线机构收放柔性绳索，将线性运动转为关节旋转 。 | 采用柔性传动介质，具备缓冲效果 ；电机可外置以减轻手指末端重量，自由度高 ；需定期维护预紧 。                                                                    |
| **直驱结构** | 舍弃中间传动，电机输出轴直接与手指关节连接，通常采用全驱动设计 。      | 无中间传动环节，传动效率与控制精度极高，响应快 ；但电机需内置，增加了末端体积与重量，对电机扭矩密度要求极高 。                                                           |

| **性能指标**        | **连杆结构**             | **腱绳结构**            | **直驱结构**           |
| --------------- | -------------------- | ------------------- | ------------------ |
| **理论抓取力 (指尖)**  | 20-50N               | 10-30N              | 30-60N             |
| **结构刚度**        | 最高（基于刚性连杆）           | 最低（受限于腱绳柔性）         | 中等（受电机轴与轴承限制）      |
| **单指自由度 (DOF)** | 2-3 个（受限于连杆运动干涉）     | 3-4 个（布线灵活，可实现复杂轨迹） | 3-4 个（受限于内置电机体积）   |
| **控制精度**        | 中等（存在多运动副的累积误差与摩擦损耗） | 最低（柔性与非线性特征增加控制难度）  | 最高（无传动误差，力/位置控制精准） |
| **系统响应时间**      | 50-100ms             | 30-80ms             | 10-50ms            |
| **整手参考重量**      | 2-3kg                | 0.8-2kg             | 2-4kg              |

| **结构方案** | **核心优势**           | **核心短板**            |
| -------- | ------------------ | ------------------- |
| **连杆结构** | 抓取力大、刚度高、可靠性强、维护简单 | 灵巧性与自由度受限，动态响应一般    |
| **腱绳结构** | 灵巧性极高、自由度多、末端重量轻   | 抓取力/刚度偏低，可靠性差，维护需求高 |
| **直驱结构** | 精度极高、响应极快、无传动磨损    | 硬件成本高、系统维护复杂、末端体积大  |
